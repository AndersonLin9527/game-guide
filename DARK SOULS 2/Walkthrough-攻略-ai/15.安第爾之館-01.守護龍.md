# DarkSoul 2-Walkthrough-攻略-15.安第爾之館-01.守護龍

## 區域攻略

* 虛影森林－歧路遺跡 → 安第爾之館－前庭
* [ ] 從「虛影森林－歧路遺跡」火點出發，走中央道路前往需要國王戒指的王之門。
* [ ] 裝備 **戒指**：國王戒指（King's Ring），等待王之門完全開啟後通過。
* [ ] 通過門後繼續前往安第爾之館，在館外擊敗 **NPC闇靈**【米勒的亞斯拉提耶爾（Aslatiel of Mirrah）】。
    * 他與露卡提耶爾同樣來自米勒，但不是可召喚NPC，也不計入露卡提耶爾任務。
* [ ] 先進入庭院左側小屋，點燃 **火點**：「安第爾之館－前庭（Foregarden）」。

* 露卡提耶爾最終事件
* [ ] 在「前庭」火點旁的小屋找到 **NPC**【米勒的露卡提耶爾】。
* [ ] **先確認露卡提耶爾已有3次Boss戰存活勝利，再與她完成最後對話。**
    * 目前主進度已確認為3／3，可以安全對話。
    * 若未達3次就把本次對話說完，她仍會離開，本周目將無法取得完整任務獎勵。
* [ ] 與露卡提耶爾對話至內容循環。
    * [ ] 取得 **武器**：米勒大劍（Mirrah Greatsword）。
    * [ ] 取得 **防具**：露卡提耶爾面具、上衣、手套、長褲。
    * [ ] 確認解鎖露卡提耶爾相關成就。
* [ ] 本區沒有露卡提耶爾的Boss召喚符；這裡是她的最終對話與贈裝節點，不是第4次任務計數機會。

* 前庭 → 主館入口
* [ ] 進入主館前探索外部階梯右側。
    * [ ] 取得 **強化素材**：餘燼（Fire Seed）×1。
* [ ] 處理庭院中的狂犬（Rabid Kobold）時，注意其原罪學者版稀有掉落。
    * [ ] 魔法：亢奮（Affinity）；若先前已由其他來源取得，可只記錄本區亦可刷取。
    * [ ] 黑騎士特大劍（Black Knight Ultra Greatsword）。
    * [ ] 黑騎士大劍（Black Knight Greatsword）。
    * [ ] 黑騎士大斧（Black Knight Greataxe）。
    * [ ] 黑騎士戟（Black Knight Halberd）。
    * [ ] Crescent Axe、Shotel 等其他稀有武器；正式繁中名稱以遊戲畫面確認。
    * 本段不要求立即刷齊；需要刷取時先裝備掉寶裝，不使用營火探究者提高區域強度。

* 主館大廳與納瓦藍
* [ ] 進入有巨大龍骨標本的主館大廳後，先清理敵人，再探索主樓梯下方兩側。
* [ ] 找到被結界囚禁的 **NPC**【宮廷魔法師納瓦藍（Royal Sorcerer Navlaan）】。
* [ ] **絕對不要拉動樓梯下另一側、滿地留言警告的拉桿。**
    * 拉桿會永久釋放納瓦藍，使本周目的暗殺委託支線失敗，並讓他在多個區域以闇靈入侵。
    * 這支拉桿與後面「上層牢籠」的控制桿不是同一個；攻略內凡提到牢籠控制桿，都不代表可以拉納瓦藍的拉桿。
* [ ] 先保持遊魂狀態，隔著結界與納瓦藍對話，開始暗殺委託支線。
    * 活人狀態只會聽到被囚禁者請你離開；必須是遊魂狀態才會與納瓦藍的人格談任務。
    * 所有委託都能用證明道具騙過他，**不需要殺死任何NPC**，證明道具也不會被收走。
* [ ] 第一個委託：出示 **梯子模型（Ladder Miniature）**。
    * [ ] 取得 **戒指**：周天祛魔戒指（Dispelling Ring；正式繁中名稱以遊戲畫面確認）。
* [ ] 第二個委託需要凱爾的頭盔（Cale's Helm）。
    * 若地圖火焰尚未全部點亮、尚未由凱爾取得完整套裝，就先停在這一步，不要殺凱爾。
* [ ] 第三個委託需要日暮之杖（Sunset Staff）。
    * 目前已由菲爾金贈送；等完成第二個委託後再出示，可取得 **咒術**：禁忌太陽（Forbidden Sun）。
* [ ] 第四個委託需要老舊羽毛（Aged Feather）。
    * 此物要在守護龍之後的龍之巢穴取得；本段先保留待辦，不殺綠衣巡使。
    * 完成後可取得 **魔法**：解放魔力（Unleash Magic），並在完整收尾後取得混沌完整套裝及開放商店。
* [ ] **完成整條支線也不必釋放納瓦藍；本周目全程不拉他的拉桿。**

* 主館大廳固定收集
* [ ] 沿主樓梯與右側上層探索。
    * [ ] 取得 **奇蹟**：強化法術防護（Great Magic Barrier）。
    * [ ] 取得 **道具**：營火探究者×2；只收集，不在本段使用。
* [ ] 進入鏡子侍從（Mirror Squire）區域，留意會從鏡中出現的敵人。
    * [ ] 取得 **戒指**：北廟祭祀戒冠＋2（Northern Ritual Band +2）。
    * [ ] 取得 **強化素材**：龍骨化石×1。
* [ ] 擊敗主館內的大型咒蛙（Giant Basilisk）。
    * [ ] 取得 **強化素材**：龍骨化石×1。
* [ ] 若要解除大廳中的石化食人魔，需消耗懷念香木×1。
    * [ ] 擊敗解除石化後的食人魔，取得 **防具**：Dragon Acolyte Mask；正式繁中名稱以遊戲畫面確認。
* [ ] 大廳與走廊中的龍之學徒（Dragon Acolyte）可留待後期集中刷取。
    * [ ] 龍之學徒完整套裝。
    * [ ] 龍賢者風帽（Dragon Sage Hood）。
    * [ ] 安第爾之槌（Aldia Hammer）。
    * [ ] 骨盾（Bone Shield）。
    * [ ] 隨機掉落的龍骨化石不計入本段固定數量。

* 原罪學者版：四座燭台與安第爾之鑰
* [ ] 找齊並點燃館內4座燭台。
    * 每點燃一座都會觸發一名 **喪失者（Forlorn）闇靈**；做好戰鬥準備後再點火。
    * 這4座燭台屬於安第爾之鑰事件，與納瓦藍的拉桿無關。
* [ ] 擊敗4次燭台觸發的喪失者。
* [ ] 回到主館巨大龍骨標本處，觸發龍骨向前撲出的事件。
    * 不要站在龍頭正前方，以免被突進撞死。
* [ ] 取得 **鑰匙**：安第爾之鑰（Aldia Key）。
* [ ] 使用安第爾之鑰開啟上鎖的實驗室並完成探索。
    * [ ] 辨識並處理室內寶箱怪；一般消耗品不列入本攻略追蹤。
    * [ ] 找到控制上層高掛牢籠的拉桿；這是牢籠控制桿，不是納瓦藍的拉桿。
* [ ] 拉動牢籠控制桿前，先確認下方落點與沿路敵人已處理，再釋放高掛牢籠中的生物。
    * [ ] 擊敗距離「前庭」較近牢籠內的寶箱怪，取得 **法杖**：黑巫女之杖（Black Witch's Staff）。
    * [ ] 擊敗另一座牢籠內的寶箱怪，取得 **道具**：懷念香木×1。

* 走廊與酸液區
* [ ] 通過後段走廊時，先找出會從牢籠或車架中出現的敵人，不要一次引到多隻食人魔。
* [ ] 進入酸液池前，卸下不想被腐蝕破壞的武器、防具與戒指；道具耐久歸零後仍需回鐵匠修理。
* [ ] 完成酸液池內的具名固定收集。
    * [ ] 取得 **魔法**：靈魂噴泉（Soul Geyser）。
    * [ ] 取得 **強化素材**：龍骨化石×1。
* [ ] 找到被鎖鏈封住的牆／門，將附近食人魔引到正確位置，誘導牠的攻擊打破障礙。
    * [ ] 開啟後方寶箱，取得 **武器**：Malformed Shell；正式繁中名稱以遊戲畫面確認。
* [ ] 找到通往Boss前區域的隱藏牆。
    * [ ] 點燃 **火點**：「安第爾之館－祭祀場（Ritual Site）」。

* 祭祀場 → 守護龍
* [ ] 若需要NPC支援，先以活人狀態在鏡子侍從區找到 **NPC**【傭兵魯特（Sellsword Luet）】的召喚符。
    * 召喚符位於二樓、會有鏡子侍從破鏡而出的鏡廊附近。
    * 他是原罪學者版的區域支援NPC；先清掉沿路敵人，可將他帶進守護龍Boss戰。
    * 他主要負責承受攻擊，傷害不高；若不想提高Boss血量，也可不召喚。
* [ ] 從「祭祀場」前進，逐間處理側邊牢房與食人魔，避免傭兵魯特在路上消耗過多生命。
* [ ] 本戰沒有米勒的露卡提耶爾或烏格的班荷特召喚符，不增加兩人的任務存活勝利次數。
* [ ] 若先前誤拉納瓦藍的拉桿，他可能在接近守護龍霧門的走廊入侵；正確全收集路線不會觸發此情況。

* Boss：守護龍
* [ ] 擊敗 **Boss**【守護龍（Guardian Dragon）】。
    * **物理弱點**：斬擊、打擊、刺擊沒有明顯差異，三者皆可正常使用；不必為了傷害類型強制換武器。
    * **屬性弱點**：魔法與闇屬性較有效；雷屬性也能正常發揮，火屬性抗性較高，不建議主打火傷。
    * **異常狀態**：可以中毒；毒箭、毒飛刀或毒武器可作為安全的額外傷害。
    * 近戰以後腿附近為主要輸出位置，砍1～2下便保留精力，提防踩踏、甩尾與轉身咬擊。
    * 守護龍飛起或攀附籠壁時，先停止鎖定並觀察頭部方向；沿火焰路徑的垂直方向衝刺離開，不要站在場地中央硬接吐息。
    * 可裝備火焰晶石戒指、施放劇烈出汗，降低失誤吃到吐息時的傷害。
* [ ] 取得並保留 **Boss魂**：守護龍的靈魂（Guardian Dragon Soul）。
    * 全收集共需2份，可向武器匠歐尼菲克斯交換 **噴火槍**、**龍翼特大劍**。
    * 本周目先保留第1份；第2份留待NG+，不為此使用營火探究者。
* [ ] Boss戰後由後方道路進入下一區「龍之巢穴」。

## 本段完成檢查

* [ ] 點燃「前庭」與「祭祀場」兩座火點。
* [ ] 露卡提耶爾3次存活勝利已確認，完成最終對話並取得米勒大劍與完整套裝。
* [ ] 以遊魂狀態開始納瓦藍支線，且**沒有拉動釋放納瓦藍的拉桿**。
* [ ] 出示梯子模型，取得封壞戒指；其餘委託依證明道具進度保留待辦，不殺NPC。
* [ ] 取得北廟祭祀戒冠＋2、強化法術防護、靈魂噴泉。
* [ ] 點燃4座燭台、擊敗4名喪失者，取得安第爾之鑰並完成上鎖實驗室。
* [ ] 取得黑巫女之杖與固定懷念香木×1。
* [ ] 取得或記錄待確認的 Dragon Acolyte Mask、Malformed Shell。
* [ ] 固定強化素材完成：餘燼×1、龍骨化石×3；本段無固定光輝楔形石。
* [ ] 確認守護龍戰不會誤計露卡提耶爾或班荷特任務次數。
* [ ] 擊敗守護龍，保留守護龍的靈魂並前往龍之巢穴。

### 留待後續，不列入本段完成條件

* [ ] 納瓦藍第二至第四個委託：等待凱爾的頭盔與龍之巢穴取得老舊羽毛後，用證明道具完成；不殺任務NPC。
* [ ] 狂犬、龍之學徒及其他敵人的稀有武器、防具與法術：後期穿掉寶裝集中處理。
* [ ] 守護龍第2份Boss魂：留待NG+，不使用營火探究者提高「祭祀場」強度。
* [ ] 下一段「龍之巢穴／龍祭壇」另行規劃；取得老舊羽毛後記得回來續做納瓦藍任務。
