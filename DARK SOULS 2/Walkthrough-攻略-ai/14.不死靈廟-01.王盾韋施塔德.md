# DarkSoul 2-Walkthrough-攻略-不死靈廟 01_王盾韋施塔德

* 不死靈廟入口 → 守墓人亞格藍德
* [ ] 從「不死靈廟-入口」火點出發，先完成原罪學者安第爾的入口對話；回答是／否不影響本段全收集。
* [ ] 進入有雷蒂雅黑魔女與遊魂的前段房間時，**不要點火把，也不要使用「照明」**。
    * 守墓人亞格藍德厭惡光源；把火把帶進他的房間、使用照明，或讓持火把遊魂追進去，都可能讓他與周圍守墓人敵對。
* [ ] 在進入亞格藍德房間前，確認身上沒有啟用中的火把／照明效果。
* [ ] 與 **NPC**【守墓人亞格藍德（Grave Warden Agdayne）】對話至內容循環。
    * [ ] 取得肢體動作：**求饒（Have Mercy!）**。
    * [ ] 先不要攻擊他；他同時是商人，也是本區 Boss 的可召喚 NPC。
* [ ] 回收前段固定道具。
    * [ ] 取得 **戒指**：暗晶石戒指＋2（Dark Quartz Ring +2）。

* 守墓人亞格藍德 → 死者棄置處
* [ ] 從亞格藍德後方繼續前進，處理札因士兵與下層遊魂。
* [ ] 在可下落的平台與梯子路線完整探索。
    * [ ] 取得 **靈魂容器**（Soul Vessel）。
    * [ ] 取得 **關鍵道具**：碎裂的眼眸寶珠（Crushed Eye Orb）。
        * 後續可用於如蜜的林德爾的利絮支線，取得全奇蹟相關的重要獎勵；本段只先收集，不急著處理支線。
    * [ ] 取得 **咒術強化素材**：火種（Fire Seed）×1。
* [ ] 搜索有大量墓碑／召喚石的房間。
    * 墓碑被敲鐘後會反覆生成雷蒂雅咒術師；優先找出並破壞召喚石，再慢慢回收道具。
    * [ ] 取得 **強化素材**：龍骨化石×1。
    * [ ] 取得 **強化素材**：光輝楔形石×1。
    * [ ] 取得 **一般強化素材**：楔形石塊×1。
* [ ] 點燃 **火點**：「不死靈廟-死者棄置處」。

* 死者棄置處周邊收集
* [ ] 從「死者棄置處」火點回收附近房間的固定收集。
    * [ ] 取得 **戒指**：封壞戒指＋2（Bracing Knuckle Ring +2）。
* [ ] 遭遇 **NPC闇靈**【無名簒奪者（Nameless Usurper）】時完成擊殺。
* [ ] 搜索闇靈路線附近的隱藏牆與鐵寶箱。
    * [ ] 取得 **武器**：亞維琳（Avelyn）。
* [ ] 完整探索下層墓碑區與側路。
    * [ ] 取得 **武器**：不遜者之槌（Mace of the Insolent）。
    * [ ] 取得 **法杖**：歐連佛德之杖（Olenford's Staff）。
    * [ ] 取得 **奇蹟**：巨雷槍（Great Lightning Spear）。
* [ ] 找到通往 Boss 前長廊的捷徑並放下橋梁，之後由「死者棄置處」可較安全地快速回到 Boss 區。

* 原罪學者版：不遜者（Insolent）收集
* [ ] 本區部分燭台點燃後會出現 **不遜者闇靈／不遜者騎士（Insolent Knight）**。
    * 這是《原罪學者》版的重要差異；若要觸發，**務必先完成亞格藍德對話並離開他的房間**，避免因光源使他敵對。
    * 不遜者為一次性敵人，適合在掉寶裝備較完整後再集中刷取；若本次沒有掉齊，不使用營火探究者補刷。
    * [ ] 不遜者兜鍪（Insolent Helm）。
    * [ ] 不遜者鎧甲（Insolent Armor）。
    * [ ] 不遜者手套（Insolent Gloves）。
    * [ ] 不遜者靴子（Insolent Boots）。
    * [ ] 不遜者之盾（Shield of the Insolent）。
    * [ ] 第二名特定不遜者會掉落 **懷念香木×1**；優先確認是否取得。
        * 取得後可回阿馬那祭壇「死者之塔」解除先前石化遊魂，完成延後收集。

* 王盾韋施塔德 Boss 前
* [ ] 在 Boss 前大廳／四個鐵寶箱完整回收固定道具。
    * [ ] 取得 **懷念香木×1**。
    * [ ] 取得暗夜石等其他固定寶箱內容；一般消耗品不列入本攻略追蹤。
* [ ] 若希望 NPC 支援，可召喚 **NPC**【守墓人亞格藍德】。
    * 召喚符位於 Boss 霧門前左側柱子附近；前提是亞格藍德仍存活且沒有敵對。
* [ ] 《原罪學者》版亦可召喚 **NPC**【虔誠的史卡蕾特（Devotee Scarlett）】。
    * 召喚符位於前段有兩名雷蒂雅黑魔女的房間柱子附近。
    * 若從「死者棄置處」走捷徑回 Boss，可先召喚她並清掉沿路敵人，避免她在路上消耗過多生命。
* [ ] **NPC任務計數確認**：王盾韋施塔德戰 **沒有米勒的露卡提耶爾，也沒有烏格的班荷特召喚符**。
    * 本戰不計入露卡提耶爾3次存活勝利。
    * 本戰不計入班荷特3次存活勝利；目前主進度仍維持班荷特有效存活勝利1／3。

* Boss：王盾-韋施塔德
* [ ] 擊敗 **Boss**【王盾-韋施塔德（Velstadt, the Royal Aegis）】。
    * 近戰以「等大槌攻擊結束 → 進場1～2刀 → 留精力翻滾」為主，不要貪刀。
    * 第二階段會跪地為聖鈴附加闇屬性並使用闇術；看到蓄力動作時可繞到側後方輸出，但不要在他重新起身時把精力打空。
    * 韋施塔德對雷屬性相對較弱；需要時可使用黃松脂或雷屬性手段提高輸出。
* [ ] 取得 **Boss魂**：王盾韋施塔德的靈魂（Soul of Velstadt）。
* [ ] 保留 **Boss魂**：王盾韋施塔德的靈魂；不可捏掉，後續納入 Boss 魂交換盤點。

* Boss 後：汎克拉德與國王戒指
* [ ] 擊敗韋施塔德後進入後方圓形房間，看到遊魂狀態的 **汎克拉德（Vendrick）**。
    * **先不要攻擊汎克拉德。** 他是獨立 Boss，建議等巨人靈魂數量準備好後再另開一段攻略處理。
* [ ] 從汎克拉德附近屍體取得 **關鍵戒指**：國王戒指（King's Ring）。
    * 國王戒指是後續開啟王之門與推進主線的重要道具。
* [ ] 取得國王戒指後返回守墓人亞格藍德並再次對話。
    * [ ] 取得 **武器**：暗朧（Darkdrift）。
    * [ ] 取得 **防具**：亞格藍德完整套裝。
* [ ] 擊敗韋施塔德後確認石頭商人克羅亞娜的新庫存。
    * [ ] 可購買光輝楔形石×3。
    * [ ] 可購買龍骨化石×3。
    * [ ] 可購買楔形石原盤×1。
    * 商店解鎖只記錄，不強制本段立即購買。

* 特別追蹤：強化素材

* [ ] 餘燼：本區固定收集未列入可確認項目；若遊戲內實際取得，依畫面名稱另補紀錄，不自行推算庫存。
* [ ] 光輝楔形石：固定取得×1；韋施塔德後克羅亞娜另開放購買×3。
* [ ] 龍骨化石：固定取得×1；韋施塔德後克羅亞娜另開放購買×3。
* [ ] 額外注意：本區另有火種×1、楔形石塊×1，不與上述三項混算。

## 本段完成檢查

* [ ] 完成不死靈廟入口至守墓人亞格藍德對話，且沒有因火把／照明讓他敵對。
* [ ] 取得碎裂的眼眸寶珠、靈魂容器、亞維琳、不遜者之槌、歐連佛德之杖、巨雷槍。
* [ ] 點燃「死者棄置處」。
* [ ] 取得封壞戒指＋2。
* [ ] 固定強化素材完成：光輝楔形石×1、龍骨化石×1；另取得火種×1、楔形石塊×1。
* [ ] 取得至少1根固定懷念香木；若同時擊殺特定不遜者，可再取得1根。
* [ ] 確認王盾韋施塔德戰沒有誤計露卡提耶爾／班荷特任務次數。
* [ ] 擊敗王盾-韋施塔德並保留其 Boss 魂。
* [ ] **沒有攻擊汎克拉德**，先取得國王戒指。
* [ ] 取得國王戒指後回報守墓人亞格藍德，領取暗朧與其完整套裝。
* [ ] 記錄韋施塔德後克羅亞娜新增光輝楔形石×3、龍骨化石×3、楔形石原盤×1庫存。

### 留待後續，不列入本段完成條件

* [ ] 汎克拉德 Boss：等巨人靈魂準備完成後另行攻略。
* [ ] 阿馬那祭壇「死者之塔」：取得本區懷念香木後回去解除石化遊魂，完成餘下固定收集與米勒法妮特事件。
* [ ] 林德爾的利絮：使用碎裂的眼眸寶珠觸發事件，涉及全奇蹟收集，建議另開支線段落處理。
* [ ] 不遜者完整防具／盾：若本輪未掉齊，後期使用掉寶裝集中處理，不使用營火探究者硬刷。
* [ ] 不使用營火探究者取得韋施塔德高強度掉落；＋2戒指等項目另依全收集規劃處理。
