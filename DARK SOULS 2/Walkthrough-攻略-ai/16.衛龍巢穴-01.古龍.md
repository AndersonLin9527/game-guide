## 區域攻略

* 安第爾之館－守護龍 → 衛龍巢穴
* [ ] 擊敗安第爾之館的守護龍後搭乘升降梯，正式進入 **衛龍巢穴（Dragon Aerie）**。
* [ ] 在入口懸崖找到 **NPC**【綠衣巡使（Emerald Herald）】，對話至內容循環。
    * [ ] 取得 **重要道具**：老舊羽毛（Aged Feather）。
    * 老舊羽毛可無限次使用，效果等同返骨片，返回最後休息的火點且不消耗道具。
    * 這也是宮廷魔法師納瓦藍第4項暗殺委託的證明道具；**只要持有即可完成委託，不需要殺綠衣巡使，也不會被納瓦藍收走。**
* [ ] 點燃 **火點**：「衛龍巢穴－衛龍巢穴（Dragon Aerie）」。

* 原罪學者版路線差異
* [ ] 確認本攻略採用 PC／PS4／PS5／Xbox One 的真正《Scholar of the First Sin》配置。
    * 火點附近的梯子在原罪學者版已經放下，可直接上去搭滑索，甚至跳過大部分衛龍巢穴前往龍祭壇。
    * 正常橋路會遇到石化遊魂擋路；若只為主線可利用梯子繞過，不必為了通行強制消耗懷念香木。
    * **本周目以全收集為目標，不建議直接跳區。**先探索3座龍巢與晶蜥，再走長吊橋前往龍祭壇。

* 衛龍巢穴探索規則
* [ ] **不要隨意打破龍蛋。**
    * 原罪學者版的3隻守護龍平時會睡著；攻擊守護龍、在牠附近打破龍蛋，或穿著月下蝶套裝太靠近，都可能把牠喚醒。
    * 最後通往龍祭壇的長吊橋會被飛龍破壞；破壞越多龍蛋，安全通過的時間越短。
* [ ] 本區共有大量晶蜥，優先使用遠程攻擊、範圍魔法或預判逃跑路線處理。
    * 本區共有11隻晶蜥；其中多隻會掉落光輝楔形石、龍骨化石與其他高階強化素材。
    * 晶蜥若失手逃掉，可休息火點重置；不需要使用營火探究者。
* [ ] 若走完整支線路線，在木橋區處理 **NPC闇靈**【劍士莎倫（Fencer Sharron）】。
    * 她是原罪學者版新增的入侵者，不是Boss，也沒有任務召喚計數。
* [ ] 若先前錯誤釋放納瓦藍，他可能在衛龍巢穴入侵；目前正確全收集路線維持納瓦藍被囚禁，因此正常情況不應遇到此入侵。

* 第一座龍巢
* [ ] 先清理爆炸遊魂與晶蜥，盡量不要讓自己的攻擊波及龍蛋。
* [ ] 取得 **武器**：龍之牙（Dragon Tooth）。
* [ ] 若要全收集3隻守護龍的原罪學者版固定掉落，再主動喚醒並擊敗第1隻 **守護龍（Guardian Dragon）**。
    * [ ] 取得 **戒指**：火晶石戒指＋2（Flame Quartz Ring +2）。
    * 本區守護龍是強敵／小Boss型敵人，**不另外計入Boss總數**。
    * **物理傷害**：斬擊、打擊、刺擊沒有值得為此換武器的明顯差距。
    * **屬性**：魔法較有效；雷也可用。火抗性高，不建議主打火傷。
    * **異常**：可中毒，可用毒箭等方式降低近身風險。

* 第二座龍巢
* [ ] 沿路回收晶蜥的高階強化素材。
* [ ] 在第二隻守護龍之前、龍蛋附近取得 **強化素材**：龍骨化石×1。
    * 不要用大範圍攻擊亂掃龍蛋；需要戰鬥時先把敵人引離蛋區。
* [ ] 擊敗第2隻守護龍。
    * [ ] 取得 **咒術**：火焰風暴（Fire Tempest）。
    * 原罪學者版此掉落為保證取得，不要混用初版的隨機掉落資料。

* 第三座龍巢
* [ ] 處理最後一批晶蜥與爆炸遊魂。
* [ ] 取得 **戒指**：邪眼戒指＋1（Ring of the Evil Eye +1）。
* [ ] 擊敗第3隻守護龍。
    * [ ] 取得 **強化素材**：光輝楔形石×1。
    * [ ] 取得 **強化素材**：龍骨化石×1。
    * [ ] 取得 **道具**：某種化石（Petrified Something）×1。
    * 原罪學者版以上3項為第3隻守護龍的保證掉落。

* 滑索與隱藏素材
* [ ] 利用滑索探索火點上方及側邊平台。
    * [ ] 在滑索可抵達／跳落的平台取得 **強化素材**：光輝楔形石×1。
    * 部分平台是單向落點，拿完後直接使用老舊羽毛回到火點即可。
* [ ] 探索完3座龍巢後，沿長吊橋快速前進，進入下一區 **龍祭壇（Dragon Shrine）**。
    * 不要在長吊橋上停留整理裝備或撿選單；飛龍會直接破壞吊橋。

* 龍祭壇入口與安第爾
* [ ] 點燃 **火點**：「龍祭壇－入口（Shrine Entrance）」。
* [ ] 若安第爾在此火點出現，與 **安第爾（Aldia）** 對話至消失。
    * 對話的「是／否」選項不影響日後安第爾Boss是否出現；真正重要的是完成三次安第爾遭遇，並在最終戰前擊敗汎克拉德王。
    * 為全Boss／完整結局路線，不要漏掉本次龍祭壇對話。

* 原罪學者版龍騎士「決鬥規則」
* [ ] 龍祭壇中的金色 **龍騎士（Dragon Knight）** 大多會向玩家敬禮而不主動攻擊，這不是Bug。
* [ ] 每一段先正面擊敗大型 **龍衛（Drakekeeper）**，再往前走。
    * 不要直接跑過龍衛；逃避決鬥會使該區龍騎士群轉為敵對。
    * 不要主動攻擊向你敬禮的龍騎士。
    * 為避免破壞決鬥規則，探索階段先不要召喚其他玩家；要打古龍時再考慮Boss前召喚。
* [ ] 最後大階梯上的雙持大劍龍騎士會主動攻擊，而且不重生；正常擊敗他後再繼續前進。

* 龍祭壇固定收集
* [ ] 使用法洛斯機關取得 **防具**：審判者套裝（Judgment Set）。
* [ ] 取得 **強化素材**：光輝楔形石×1。
* [ ] 取得 **武器**：札因大斧（Drakekeeper's Greataxe）。
* [ ] 取得 **盾牌**：札因大盾（Drakekeeper's Greatshield）。
* [ ] 取得 **強化素材**：楔形石原盤×1。
* [ ] 取得 **戒指**：三龍戒指（Third Dragon Ring）。
    * 這是本周目全戒指的重要固定收集，不要漏拿。
* [ ] 在高塔遭遇並擊敗 **NPC闇靈**【龍牙威亞德（Dragonfang Villard）】。
* [ ] 取得 **重要道具**：化石蛋（Petrified Egg）。
    * 之後交給熔鐵城的行商人馬格赫拉德，可加入古龍後裔誓約；交出去是正確用途，不會失去全收集進度。
* [ ] 取得 **盾牌**：衛龍盾（Watchdragon Parma）。
    * 此盾有提升掉寶率的特殊效果，可納入日後刷裝備配置。
* [ ] 從化石蛋區往下方平台落下，開啟寶箱。
    * [ ] 取得 **魔法**：結晶魔法武器（Crystal Magic Weapon）。
    * [ ] 取得 **道具**：懷念香木×1。
    * 原罪學者版此處是「結晶魔法武器＋懷念香木」；不要混用初版掉落配置。

* 古龍前：先對話，不要一見面就砍
* [ ] 抵達龍祭壇最上層，找到 **NPC／可選Boss**【古龍（Ancient Dragon）】。
* [ ] **第一次到達時先對話，不要攻擊。**
    * [ ] 取得 **重要道具**：灰霧核心（Ashen Mist Heart）。
    * 灰霧核心可進入巨人與龍的記憶，是後續巨人王、古龍的靈魂等收集的必要道具。
    * 取得灰霧核心本身就完成龍祭壇的主線目的；古龍戰不是推進主線的必要Boss。

* Boss召喚與任務計數
* [ ] 古龍戰可使用的NPC召喚包含：
    * **溫格之首（Head of Vengarl）**：完成其相關進度後可用。
    * **屠夫梅琳達（Melinda the Butcher）**：先前擊敗她的入侵版本後可用。
    * **害羞的雷（Bashful Ray）**：原罪學者版限定，小白符召喚。
* 本戰 **沒有米勒的魯卡提耶或烏格的班荷特召喚符**，不增加兩人的任務存活勝利次數。
* 古龍血量很高，而NPC很容易被大範圍火焰秒殺；若目的是穩定擊殺，通常單挑比帶NPC更容易控制Boss動作。

* Boss：古龍（可選）
* [ ] 若本階段要推進「全Boss」目標，在取得灰霧核心後再攻擊古龍並進入Boss戰。
    * 若目前只想推主線，可以先保留古龍，之後在挑戰汎克拉德王前回來擊殺即可。
    * **物理弱點**：斬擊、打擊、刺擊效果相同，沒有「特別怕刺」或「特別怕砍」。
    * **屬性弱點**：沒有明顯的元素弱點；火抗性極高，**最不推薦火屬性**。魔法、雷、闇可正常使用，但不算特別脆弱。
    * **異常狀態**：可中毒、可出血；但Boss血量很高，異常只適合作為額外傷害。
    * 近戰最穩定的打法是貼住後腳腳趾附近輸出；看到抬腳就閃避踩踏，再移動到另一隻後腳，反覆控制Boss只使用踩踏與少量飛空攻擊。
    * 若古龍起飛，立刻往尾巴方向全力衝刺離開落火範圍，不要貪刀，也不要停在場地中央鎖定抬頭看。
    * 可使用火晶石戒指＋2、劇烈出汗等方式提高火防；古龍的火焰傷害非常高，火防能大幅增加容錯。
    * 戰鬥時間長，建議攜帶修理光粉或準備第二把已強化武器，避免主武器耐久耗盡。
* [ ] 擊敗古龍後取得：
    * [ ] **巨人們的靈魂（Soul of a Giant）**×1。
    * [ ] **強化素材**：龍骨化石×1。
    * **古龍不會掉落「古龍的靈魂」。**古龍的靈魂要在取得灰霧核心後，前往輝石鎮蓋多勒夫雷迪亞Boss房的龍之記憶取得。

## 本段強化素材追蹤

* **餘燼（Fire Seed）**：本段「衛龍巢穴／龍祭壇」沒有需要追蹤的固定餘燼。
* [ ] 龍骨化石×1：衛龍巢穴第二座龍巢前、龍蛋附近的固定拾取。
* [ ] 龍骨化石×1：衛龍巢穴第3隻守護龍保證掉落。
* [ ] 龍骨化石×4：衛龍巢穴指定晶蜥各掉落×1；屬晶蜥固定掉落，失手可休息火點重置晶蜥後重試。
* [ ] 龍骨化石×1：擊敗古龍後固定掉落；若本段先不打古龍則保留待辦。
* [ ] 光輝楔形石×1：衛龍巢穴第3隻守護龍保證掉落。
* [ ] 光輝楔形石×1：衛龍巢穴滑索／側邊平台固定拾取。
* [ ] 光輝楔形石×1：龍祭壇固定寶箱。
* [ ] 衛龍巢穴其他晶蜥掉落的光輝楔形石：逐隻清理即可，不使用營火探究者提高區域強度。
* [ ] 楔形石原盤×1：龍祭壇固定寶箱。
* 本區是中後期非常密集的龍骨化石與光輝楔形石來源，但目前仍維持「不使用營火探究者」原則；本周目先拿自然強度1的全部固定素材即可。

## 本段完成檢查

* [ ] 與綠衣巡使對話並取得老舊羽毛。
* [ ] 點燃衛龍巢穴火點，完整探索3座龍巢，不直接利用原罪學者版捷徑跳過全區。
* [ ] 不破壞大量龍蛋，安全通過最後長吊橋。
* [ ] 取得龍之牙、火晶石戒指＋2、火焰風暴、邪眼戒指＋1。
* [ ] 清理11隻晶蜥並回收本周目可取得的高階強化素材。
* [ ] 取得衛龍巢穴固定龍骨化石與光輝楔形石。
* [ ] 點燃龍祭壇入口火點，完成安第爾第3次對話，不漏掉最終Boss前置條件。
* [ ] 依原罪學者版決鬥規則逐一擊敗龍衛，不讓黑龍騎士群全面敵對。
* [ ] 取得審判者套裝、札因大斧、札因大盾、三龍戒指、衛龍盾。
* [ ] 取得化石蛋，保留給行商人馬格赫拉德開啟古龍後裔誓約。
* [ ] 取得結晶魔法武器與原罪學者版同箱的懷念香木。
* [ ] 與古龍對話並取得灰霧核心，**確認已拿到後才考慮古龍Boss戰**。
* [ ] 確認古龍戰沒有魯卡提耶或班荷特任務計數。

### 可延後，不列入主線完成條件

* [ ] 擊敗可選Boss古龍，取得巨人們的靈魂與龍骨化石；全Boss目標最終仍需完成。
* [ ] 回安第爾之館向納瓦藍出示老舊羽毛，完成第4項暗殺委託；前提是第2、第3項也已依序完成。
* [ ] 將化石蛋交給熔鐵城的行商人馬格赫拉德，加入古龍後裔誓約並取得古龍徽記、古龍眼珠。
* [ ] 使用灰霧核心前往夫雷迪亞Boss房的龍之記憶，取得古龍的靈魂；之後向武器匠歐尼菲克斯交換對應Boss魂武器。
* [ ] 龍祭壇龍衛、龍騎士等敵人的稀有武器與防具，留待穿掉寶裝後集中刷取。

## 後續追蹤

### 支線任務-NPC 宮廷魔法師納瓦藍暗殺任務

* [ ] 取得老舊羽毛後，返回安第爾之館，以遊魂狀態隔著結界與 **宮廷魔法師納瓦藍** 對話。
* [ ] 依序完成尚未完成的委託；不能跳過中間任務直接交老舊羽毛。
    * [ ] 第2項：出示凱爾的頭盔，取得愚者的香料。
    * [ ] 第3項：出示日暮之杖，取得咒術「禁忌太陽」。
    * [ ] 第4項：出示老舊羽毛，取得魔法「解放魔力（Unleash Magic）」。
* [ ] 完成全部委託後確認納瓦藍商店與混沌完整套裝等獎勵；**全程不需要拉動釋放納瓦藍的拉桿。**

### 誓約-古龍後裔

* [ ] 將龍祭壇取得的 **化石蛋（Petrified Egg）** 交給熔鐵城的 **行商人馬格赫拉德（Magerold of Lanafir）**。
* [ ] 加入 **古龍後裔（Dragon Remnants）** 誓約。
    * [ ] 取得 **戒指**：古龍徽記（Ancient Dragon Seal）。
    * [ ] 取得 **多人道具**：古龍眼珠（Dragon Eye）。
* 化石蛋的主要用途就是開啟此誓約，可以安全交給馬格赫拉德。

### 古龍的靈魂與龍之記憶

* [ ] 取得灰霧核心後回到 **輝石鎮蓋多勒－公爵的夫雷迪亞Boss房**。
* [ ] 對場地中的古龍遺骸使用灰霧核心，進入 **龍之記憶（Dragon Memories）**。
* [ ] 取得 **Boss魂**：古龍的靈魂（Ancient Dragon Soul）。
    * 古龍的靈魂與龍祭壇活著的古龍是兩個不同取得機制；擊殺龍祭壇古龍不會掉這顆魂。
    * [ ] 向武器匠歐尼菲克斯以古龍的靈魂交換 **彎曲龍之大劍（Curved Dragon Greatsword）**。

### 掉落收集-衛龍巢穴與龍祭壇

* [ ] 衛龍巢穴的黑暗祭司／祭司系敵人可留待後期集中刷取：
    * [ ] 祭司頭飾。
    * [ ] 祭司長袍。
    * [ ] 祭司手套。
    * [ ] 祭司裙。
