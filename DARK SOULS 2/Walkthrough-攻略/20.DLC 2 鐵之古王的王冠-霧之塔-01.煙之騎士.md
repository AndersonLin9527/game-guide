## 區域攻略

* 起點：如密。
* 本段目標：進入DLC2「鐵之古王的王冠」，完整探索霧之塔主路線，取得榮華大劍、固定光輝楔形石×6、龍骨化石×10，並擊敗煙之騎士。
* 米勒的魯卡提耶與烏格的班荷特任務均已完成；本段的召喚NPC不增加兩人的任務次數。
* 霧之塔是垂直多層地圖。先取得灼熱鐵權杖並啟動中央電梯，再回收早先無法到達的平台與房間。

### 如密出發與沉重鐵鑰

* [ ] 在如密整理裝備、修理武器並補滿遠程彈藥。
* [ ] 檢查重要道具欄是否已有沉重鐵鑰（Heavy Iron Key）。
* 若尚未取得：
  * [ ] 傳送至巨人隕落之森。
  * [ ] 前往最後的巨人附近、火蜥蜴所在的洞窟。
  * [ ] 回收洞窟內的沉重鐵鑰。
  * 火蜥蜴火焰傷害高；可從已開放的正式入口進入，不必冒險從高處硬摔。
* [ ] 確認沉重鐵鑰已在重要道具欄。

### 進入鐵之古王的王冠

* [ ] 傳送至熔鐵之王後方的始源營火。
* [ ] 調查房間後方的DLC祭壇，傳送到DLC2入口。
* [ ] 搭乘升降台，使用沉重鐵鑰開啟大門。
* [ ] 穿過霧門並沿巨型鎖鏈前往霧之塔。
* [ ] 點燃營火「王座層（Throne Floor）」。

### 霧之塔頂層與熔鐵楔

* [ ] 在跨越第一條巨型鎖鏈前，從灰燼遺骸取得熔鐵楔×6。
* 熔鐵楔是有限道具，用來破壞灰燼偶像並取得娜德拉靈魂碎片。
* **從這6個熔鐵楔中至少保留4個。** 煙之騎士場外有4座會替Boss快速回血的灰燼偶像，開戰前必須優先破壞。
* 安全安排：
  * 初始6個熔鐵楔，在拿到後續4個以前最多只使用2個。
  * 取得後續4個後，先確認身上仍有4個留給Boss場外偶像。
  * 最後1個熔鐵楔要到擊敗亞倫騎士後才取得，因此本段不可能立刻清完全部灰燼偶像。
* [ ] 第一座灰燼偶像：可先保留；若使用熔鐵楔，記錄取得1個娜德拉靈魂碎片。
* [ ] 從第一座灰燼偶像後方樓梯下方取得敏捷戒指。

### 王座層至上層

* [ ] 依序下降圓形平台與灰燼區，逐批引出灰燼戰士，避免被包圍。
* [ ] 梯子區回收鐮刀＋7與稜彩石×10。
* [ ] 金屬寶箱取得楔形石原盤。
* [ ] 灰燼偶像與多名灰燼戰士的大房間：先處理能強化／治療敵人的偶像，再清敵。
* [ ] 右側小房取得咒術「火焰之舞（Dance of Fire）」。
* [ ] 拉動拉桿開啟大門。
* [ ] 明顯的隱藏牆後回收靈魂容器×2、古老輝滴石×4、枯萎黃昏草×4。
* [ ] 裝滿炸藥桶的敵人可用弓箭、火焰壺或引誘方式引爆；不要近身和鐵戰士同時混戰。
* [ ] 木寶箱取得拳套＋8。
* [ ] 點燃營火「上層（Upper Floor）」。
* [ ] 回收火晶石戒指＋3。
* [ ] Possessed Armor伏擊區回收光輝楔形石×2。
* [ ] 灰燼平台的可破壞灰像中回收多種大型靈魂。

### 暗殺者馬爾德隆與榮華大劍

* [ ] 從上層通往側塔的鎖鏈時，觸發入侵NPC「暗殺者馬爾德隆（Maldron the Assassin）」。
* 馬爾德隆受傷後會向塔底逃跑，並試圖把玩家帶進詛咒與敵群；不要盲目追下去。
* 建議先把沿路敵人與灰燼偶像處理好，再逐層壓縮他的逃跑路線。
* [ ] 塔頂金屬寶箱取得營火探究者×2。
* [ ] 螺旋樓梯回收銀色護符×5。
* [ ] 中央柱平台取得亞倫大弓＋5。
* [ ] 抵達側塔底部，開啟寶箱取得 **榮華大劍（Majestic Greatsword）**。
* [ ] 塔底灰像回收蒼光石×2。
* 榮華大劍使用龍骨化石強化；放在左手時具有特殊動作。需求為力氣25、敏捷25、智力20、信仰20。

### 前廳與灼熱鐵權杖

* [ ] 抵達營火「前廳（Foyer）」。
* [ ] 前廳主室取得法術晶石戒指＋3。
* [ ] 炸藥桶房間利用桶裝敵人炸開兩面有裂痕的牆：
  * [ ] 第一個秘密房取得卡塔利納護手、卡塔利納腿甲。
  * [ ] 第二個秘密房取得 **龍骨化石×8**。
* [ ] 前往灼燒者之塔前，在梯子附近取得 **龍骨化石×2**。
* [ ] 灼燒者之塔側房取得闇術「追憶（Recollection）」與 **光輝楔形石×2**。
* [ ] 清理灼燒者房間後取得灼熱鐵權杖（Scorching Iron Scepter）。
* 取得權杖時房內敵人會集體甦醒；先規劃退路，不要在拾取點硬扛。
* [ ] 回到前廳中央裝置，放入灼熱鐵權杖，啟動霧之塔電梯系統。

### 啟動電梯後的回收

* [ ] 回到王座層與前廳之間的電梯路線，取得凶鳥戒指。
* [ ] 電梯隱藏牆房取得遊魂皮。
* [ ] 上層捷徑房取得愚者戒指。
* [ ] 窄平台寶箱取得朝聖者刺槍（Pilgrim's Spontoon）。
* [ ] 鐵戰士與灰燼偶像房取得生命戒指＋3。
* [ ] 上層雙層走廊，用桶裝敵人炸開牆壁，取得周天魔戒指＋1。
* [ ] 走廊盡頭寶箱取得熔鐵楔×4。
* [ ] 電梯上升途中跳上側邊平台，擊殺晶蜥並取得金屬寶箱內光蟲×2。
* [ ] 三名鐵戰士伏擊的灰燼平台：
  * [ ] 取得塔之鑰。
  * [ ] 取得 **光輝楔形石×2**。
  * [ ] 同區其餘固定素材與消耗品完成回收。
* [ ] 使用塔之鑰開門，回收咒術「火蛇（Fire Snake）」。
* [ ] 通往最下層的多層平台：
  * [ ] 上層金屬寶箱取得力之戒指。
  * [ ] 下層取得游擊槍＋6。
* [ ] 前往最下層前的側房，金屬寶箱取得魔法怪手戒指。

### 最下層與煙之騎士前置

* [ ] 點燃營火「最下層（Lowermost Floor）」。
* [ ] 回收灰像內勇敢戰士的大靈魂與楔形石塊×3。
* [ ] 觸發並擊敗入侵NPC「快劍瑞秋（Quicksword Rachel）」。
* [ ] Boss霧門外共有4座灰燼偶像；使用熔鐵楔逐一破壞。
* [ ] 確認4座偶像全部失效後才進Boss霧門。
* 若少破壞任何一座，煙之騎士靠近該區時會快速回血，會讓戰鬥明顯惡化。

#### 可召喚NPC

* [ ] 鋼鐵意志艾莉（Steelheart Ellie）。
* [ ] 晦冥的卡里昂（Carhillion of the Fold）。
* 兩位NPC都不屬於需要靠Boss存活勝利推進的任務，本戰召喚與否不影響NPC支線完成度。
* 煙之騎士會因召喚而增加生命與抗性；卡里昂輸出與生存較弱，若已能穩定閃避，單人通常更容易掌握Boss節奏。

### Boss：煙之騎士 Fume Knight

#### 弱點與抗性

| 類型 | 結論 |
|------|------|
| 打擊 | 相對推薦；錘類攻擊後搖較短時尤其適合 |
| 斬擊 | 正常，沒有明顯額外弱點 |
| 刺擊 | 正常，沒有明顯額外弱點 |
| 火   | **極高抗性，不建議** |
| 魔法 | 高抗性 |
| 雷   | 中等抗性；元素中相對可用 |
| 闇   | 中等抗性 |
| 毒／猛毒 | 無效 |
| 出血 | 無效 |

* **黑暗武器提醒：** 並非完全無效，但煙之騎士有中等闇抗性；不要把闇屬性當成主要弱點。若武器本身物理攻擊高，優先維持穩定物理傷害；需要額外元素時可比較黃金松脂／雷附魔的實際傷害。
* 純法術在三王冠DLC敵人身上的實際傷害會被額外壓低；近戰附魔通常比只依賴單一純法術穩定。
* 不要使用火焰武器、火脂或火系咒術作為主力。

#### 第一階段

* 煙之騎士同時使用煙之劍與煙之特大劍。
* 快劍攻擊出手快，特大劍攻擊較慢且常作為連段終結。
* 看到特大劍慢揮後再反擊；每次以1下為基準，不要預設連段已經結束。
* 裝備負重保持較低，精力至少保留一次翻滾。
* 盾牌可以應急擋小劍，但特大劍會大量削減精力，主防禦仍以翻滾為主。

#### 第二階段

* 約60%生命時，Boss丟棄小劍並替特大劍附上火＋闇力量。
* 強化期間可以輸出，但強化結束後常接大範圍慢橫掃，不可貪刀。
* 慢速火焰橫掃：向Boss與劍身方向斜前翻滾，穿過攻擊後只反擊1次。
* 插劍爆炸＋旋轉火球：先離開近身爆炸範圍，再從火球間隙穿過；這也是安全喝元素瓶的機會。
* 奔跑突刺／跳劈：側翻後反擊1次。
* 第二階段連段可能臨時追加攻擊；未看清收招前不要連續輸出。

#### 特殊注意

* 裝備韋施塔德兜鍪進場，會使煙之騎士立刻進入特大劍強化狀態；一般攻略不建議這樣做。
* NPC召喚會提高Boss耐久，而且兩名NPC不擅長迴避；若召喚後更難打，改成單人並不是退步，而是更容易控制攻擊方向。
* [ ] 擊敗煙之騎士。
  * [ ] 取得煙之騎士的靈魂。
  * [ ] 取得本周目對應的娜德拉靈魂碎片。
  * [ ] Boss後方小房取得鐵之古王的王冠。

### 娜德拉靈魂與熔鐵楔

* 每破壞1座灰燼偶像可取得1個娜德拉靈魂碎片。
* 本周目需集齊12個碎片，才會組成完整的娜德拉靈魂。
* 霧之塔初始取得熔鐵楔×6，啟動電梯後再取得×4。
* 最後1個熔鐵楔要在擊敗亞倫騎士後取得，因此完整娜德拉靈魂要等DLC2後續路線。
* 完整娜德拉靈魂全收集需要2份：尖叫之鈴、咒術「放逐」各消耗1份，正常安排需跨周目。
