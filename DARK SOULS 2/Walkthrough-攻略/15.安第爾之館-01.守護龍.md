## 區域攻略

* 虛影森林－歧路遺跡 → 安第爾之館－前庭
* [x] 從「虛影森林－歧路遺跡」火點出發，走中央道路前往需要國王戒指的王之門。
* [x] 裝備 **戒指**：國王戒指（King's Ring），等待王之門完全開啟後通過。
* [x] 點燃 **火點**：「安第爾之館－前庭（Foregarden）」。

* 魯卡提耶最終事件
* [x] 找到 **NPC** 米勒的魯卡提耶。
* [x] **先確認魯卡提耶已有3次Boss戰存活勝利，再與她完成最後對話。**
    * 目前主進度已確認為3／3，可以安全對話。
    * 若未達3次就把本次對話說完，她仍會離開，本周目將無法取得完整任務獎勵。
    * [x] 與魯卡提耶對話至內容循環。
    * [x] 取得 **武器** 米勒大劍（Mirrah Greatsword）。
    * [x] 取得 **防具** 魯卡提耶面具、背心、手套、長褲。
    * [x] 解鎖 **成就** 亞凱提拉：接獲米勒的魯卡提耶轉贈。
* [x] 探索前庭左側、主館外牆旁的鐵寶箱怪。
    * [x] 取得 **防具**：黑暗面罩（Dark Mask）。
    * [x] 取得 **法杖**：日暮之杖（Sunset Staff）；即使先前已由菲爾金取得，本處仍可取得另一把。

* 前庭 → 主館入口
* [x] 進入王之門後，探索入口左側樹旁屍體，取得 **強化素材**：龍骨化石×1。
* [x] 進入主館前探索外部階梯右側。
    * [x] 取得 **強化素材**：餘燼（Fire Seed）×1。
* [x] 前庭的狂犬（Rabid Kobold）有[掉落收集](#掉落收集-前庭的狂犬)。
* [x] 進入安第爾之館，在館外擊敗 **闇靈** 米勒的阿茲拉提耶（Aslatiel of Mirrah）。

* 主館大廳與納瓦藍
* [x] 進入有巨大龍骨標本的主館大廳後，先清理敵人，再探索主樓梯下方兩側。
* [x] 找到被結界囚禁的 **NPC** 宮廷魔法師納瓦藍（Royal Sorcerer Navlaan）。
* [x] **絕對不要拉動樓梯下另一側、滿地留言警告的拉桿。**
    * 拉桿會永久釋放納瓦藍，使本周目的暗殺委託支線失敗，並讓他在多個區域以闇靈入侵。
    * 這支拉桿與後面「上層牢籠」的控制桿不是同一個；攻略內凡提到牢籠控制桿，都不代表可以拉納瓦藍的拉桿。
* **NPC** 宮廷魔法師納瓦藍有[支線任務](#支線任務-npc-宮廷魔法師納瓦藍暗殺任務)。

* 主館大廳固定收集
* [x] 沿主樓梯與右側上層探索。
    * [x] 取得 **奇蹟**：強化法術防護（Great Magic Barrier）。
    * [x] 取得 **道具**：營火探究者×2；只收集，不在本段使用。
* [x] 進入鏡子侍從（Mirror Squire）區域，留意會從鏡中出現的敵人。
    * [x] 取得 **戒指**：北廟祭祀戒冠＋2（Northern Ritual Band +2）。
    * [x] 取得 **強化素材**：龍骨化石×1。
* [x] 擊敗主館內的大型咒蛙（Giant Basilisk）。
    * [x] 本次掉落取得 **強化素材**：龍骨化石×1；不列入地圖固定拾取數量。
    * [ ] 後期刷取 **防具**：龍學師風帽（Dragon Sage Hood）；屬隨機掉落，不因擊敗咒蛙就視為已取得。
* [x] 若要解除大廳中的石化食人魔，需消耗懷念香木×1。
    * [ ] 擊敗解除石化後的食人魔，取得 **裝備**：龍學徒面罩（Dragon Acolyte Mask）。
* [x] 大廳與走廊中的龍之學徒（Dragon Acolyte）有[掉落收集](#掉落收集-龍之學徒)。

* 四座燭台與安第爾之鑰
* [x] 找齊並點燃館內4座燭台。
    * 每點燃一座都會觸發一名 **喪失者（Forlorn）闇靈**；做好戰鬥準備後再點火。
    * 這4座燭台屬於安第爾之鑰事件，與納瓦藍的拉桿無關。
    * [x] 巨大龍骨的龍頭後方。
    * [x] 主樓梯右側上層的走廊內。
    * [x] 後段酸液池旁。
    * [x] 封住異形之殼寶箱房的鎖鏈門附近。
    * 參考 [YouTube 黑暗靈魂2 原罪哲人 -「安第爾之館」鑰匙獲取攻略](https://www.youtube.com/watch?v=B5KAkJL27xQ)
* [x] 擊敗4次燭台觸發的喪失者。
* [x] 回到主館巨大龍骨標本處，觸發龍骨向前撲出的事件。
    * 不要站在龍頭正前方，以免被突進撞死。
* [x] 取得 **鑰匙**：安第爾之鑰（Aldia Key）。
* [x] 使用安第爾之鑰開啟上鎖的實驗室並完成探索。
    * [x] 辨識並處理室內3個寶箱怪；一般消耗品不列入本攻略追蹤。
    * [x] 找到控制上層高掛牢籠的拉桿；這是牢籠控制桿，不是納瓦藍的拉桿。
* [x] 拉動牢籠控制桿前，先確認下方落點與沿路敵人已處理，再釋放高掛牢籠中的生物。
    * [x] 擊敗距離「前庭」較近牢籠內的寶箱怪，取得 **法杖**：魔女黑枝。
    * [x] 擊敗另一座牢籠內的寶箱怪，取得 **道具**：懷念香木×1。
    * [x] 擊敗牢籠釋放的強化不死人（Enhanced Undead／Undead Aberration），取得固定掉落 **強化素材**：光輝楔形石×3。
    * [x] 擊敗館內牢籠中的石像鬼（Belfry Gargoyle），取得固定掉落 **強化素材**：光輝楔形石×1；本區個體不是獨立Boss，不重複計入Boss總數。
    * 強化不死人的混沌之盾等稀有裝備另列[後續收集](#掉落收集-其他敵人)，不是牢籠內保證可拾取的盾牌。

* 走廊與酸液區
* [x] 通過後段走廊時，先找出會從牢籠或車架中出現的敵人，不要一次引到多隻食人魔。
* [x] 找到通往Boss前區域的隱藏牆，位於酸液池樓梯中間。
    * [x] 點燃 **火點**：「安第爾之館－祭祀場（Ritual Site）」。
* [x] 進入酸液池前，卸下不想被腐蝕破壞的武器、防具與戒指；道具耐久歸零後仍需回鐵匠修理。
* [x] 完成酸液池內的具名固定收集。
    * [x] 取得 **魔法**：靈魂洪流（Soul Geyser）。
    * [x] 取得 **強化素材**：龍骨化石×1。
* [x] 找到被鎖鏈封住的牆／門，將附近食人魔引到正確位置，誘導牠的攻擊打破障礙。
    * [x] 開啟後方寶箱，取得 **武器**：異形之殼（Malformed Shell）。

* 祭祀場 → 守護龍
* [x] 若需要NPC支援，先以活人狀態在鏡子侍從區找到 **NPC**【傭兵魯特（Sellsword Luet）】的召喚符。
    * 召喚符位於二樓、會有鏡子侍從破鏡而出的鏡廊附近。
    * 他是原罪學者版的區域支援NPC；先清掉沿路敵人，可將他帶進守護龍Boss戰。
    * 他主要負責承受攻擊，傷害不高；若不想提高Boss血量，也可不召喚。
* [x] 從「祭祀場」前進，逐間處理側邊牢房與食人魔，避免傭兵魯特在路上消耗過多生命。
* [x] 本戰沒有米勒的魯卡提耶或烏格的班荷特召喚符，不增加兩人的任務存活勝利次數。
* [x] 若先前誤拉納瓦藍的拉桿，他可能在接近守護龍霧門的走廊入侵；正確全收集路線不會觸發此情況。

* Boss：守護龍
* [x] 擊敗 **Boss**【守護龍（Guardian Dragon）】。
    * **物理弱點**：斬擊、打擊、刺擊沒有明顯差異，三者皆可正常使用；不必為了傷害類型強制換武器。
    * **屬性弱點**：優先考慮魔法傷害；雷屬性也可使用。火屬性抗性較高，不建議主打火傷；不將闇屬性特別列為主要弱點。
    * **異常狀態**：可以中毒；毒箭、毒飛刀或毒武器可作為安全的額外傷害。
    * 近戰以後腿附近為主要輸出位置，砍1～2下便保留精力，提防踩踏、甩尾與轉身咬擊。
    * 守護龍飛起或攀附籠壁時，先停止鎖定並觀察頭部方向；沿火焰路徑的垂直方向衝刺離開，不要站在場地中央硬接吐息。
    * 可裝備火晶石戒指、施放劇烈出汗，降低失誤吃到吐息時的傷害。
* [x] 取得並保留 **Boss魂**：守護龍的靈魂（Guardian Dragon Soul）。
    * 全收集共需2份，可向武器匠歐尼菲克斯交換 **噴火槍**、 **龍翼特大劍**。
    * 本周目先保留第1份；第2份留待NG+，不為此使用營火探究者。
* [x] Boss戰後由後方道路進入下一區「衛龍巢穴」。
* [x] 點燃 **火點**：「衛龍巢穴－衛龍巢穴」；目前位置停在此處，後續探索與老舊羽毛取得另行確認。

## 後續追蹤

### 支線任務-NPC 宮廷魔法師納瓦藍暗殺任務

* **NPC** 宮廷魔法師納瓦藍（Royal Sorcerer Navlaan）暗殺任務。
    * [x] 先保持遊魂狀態，隔著結界與納瓦藍對話，開始暗殺委託支線。
    * 活人狀態只會聽到被囚禁者請你離開；必須是遊魂狀態才會與納瓦藍的人格談任務。
    * 所有委託都能用證明道具騙過他， **不需要殺死任何NPC**，證明道具也不會被收走。
    * [x] 第一個委託：出示 **梯子模型（Ladder Miniature）**。
        * [x] 取得 **戒指**：周天魔戒指（Dispelling Ring）。
    * [ ] 第二個委託需要凱爾的頭盔（Cale's Helm）。
        * 若地圖火焰尚未全部點亮、尚未由凱爾取得完整套裝，就先停在這一步，不要殺凱爾。
        * [ ] 出示頭盔後取得 **香料**：愚者的香料（Simpleton's Spice）。
    * [ ] 第三個委託需要日暮之杖（Sunset Staff）。
        * 目前已由菲爾金贈送；等完成第二個委託後再出示，可取得 **咒術**：禁忌太陽（Forbidden Sun）。
    * [ ] 第四個委託需要老舊羽毛（Aged Feather）。
        * 此物要在守護龍之後的衛龍巢穴取得；本段先保留待辦，不殺綠衣巡使。
        * 完成後可取得 **魔法**：解放魔力（Unleash Magic），並在完整收尾後取得混沌完整套裝及開放商店。
    * [ ] **完成整條支線也不必釋放納瓦藍；本周目全程不拉他的拉桿。**

### 掉落收集-其他敵人

* [ ] 強化不死人（Enhanced Undead／Undead Aberration）：混沌之盾（Chaos Shield）取得狀態待確認；屬稀有掉落，不寫成固定拾取。
    * 《原罪學者》也可向流放術士菲爾金購買混沌之盾，作為後續補收方式。
* [ ] 強化不死人：混沌刺劍（Chaos Rapier）取得狀態待確認；可一併核對菲爾金商店，未回報前不勾選。
* 龍學師風帽由大型咒蛙隨機掉落，待辦列在「主館大廳固定收集」咒蛙項目；不列入龍之學徒套裝。
