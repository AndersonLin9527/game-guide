### 回收：巨人殞落之森—火蜥蜴坑

位於：主塔（Cardinal Tower）→ 往最後的巨人升降梯 → 使用鎔鐵鑰匙（Iron Key）開啟升降梯旁的門

* 此區為真正《原罪學者》配置；火蜥蜴坑內共有4隻火蜥蜴（Flame Salamander）。
* 火蜥蜴完全免疫火屬性；近戰刺擊效果較佳，魔法、雷、闇皆可使用。
* 建議由鎔鐵鑰匙正門進入，不建議由主塔上方直接跳入火坑。
* [ ] 取得 **戒指** 老鷹戒指（Hawk Ring）。
    * 進入火蜥蜴坑後往左側斜坡上行；火晶石戒指＋1寶箱對面的屍體取得。
* [x] 取得 **戒指** 火晶石戒指＋1（Flame Quartz Ring +1）。
    * 位於左側斜坡上層的金屬寶箱。
* [ ] 取得 **強化素材** 火龍石（Firedrake Stone）×1。
* [ ] 取得 **大盾** 反叛大盾（Rebel's Greatshield）。
* [ ] 取得 **鑰匙** 重鐵鑰（Heavy Iron Key）。
    * 反叛大盾與重鐵鑰位於坑內後方右側同一具屍體；重鐵鑰用於開啟黑霧之塔（Crown of the Old Iron King）入口。
* 火蜥蜴可隨機掉落咒術「火球」、「火焰彈」與「大火球」；火球與火焰彈已透過羅莎貝娜取得，不需要在此硬刷。

### Boss：巨人王（Giant Lord）

| 類型 | 承傷效率 |
|------|---------:|
| 打擊 |     100% |
| 斬擊 |     100% |
| 刺擊 |     100% |
| 魔法 |      70% |
| 雷   |      70% |
| 火   |      70% |
| 闇   |  **90%** |
| 毒   |      70% |
| 出血 |      70% |

* 物理：斬擊、打擊、刺擊承傷相同，不需要特別更換物理傷害類型。
* 元素：闇屬性承傷效率90%，高於魔法、雷、火的70%；可優先使用黑暗武器（Dark Weapon）附魔。
* 異常：可中毒、可出血。
* 近戰：貼近腳踝附近輸出，觀察踩踏與大劍橫掃後反擊。
* 遠程：保持距離時注意巨人王的遠距離劍氣。
* [ ] 讓烏格的班荷特參戰並存活。
* [ ] 擊敗巨人王。
    * [ ] 取得巨人王的靈魂（Giant Lord Soul）。
    * [ ] 取得巨人的共鳴（Giant's Kinship）。
* [ ] 前往記憶末端取得巨人們的靈魂×1。
