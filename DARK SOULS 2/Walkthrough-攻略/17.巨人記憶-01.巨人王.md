# DarkSoul 2-Walkthrough-攻略-17.巨人記憶-01.巨人王

## 區域攻略

* 如蜜 → 巨人隕落之森 → 巨人記憶
* [x] 由如蜜傳送至巨人隕落之森，依序探索三個巨人記憶。
* [x] 確認已持有灰霧核心（Ashen Mist Heart）。
* [x] 巨人們的靈魂（Soul of a Giant）全部保留，不使用。
* [x] 本段不使用營火探究者。

### 巨人奧捷的記憶（Memory of Vammar）

* [ ] 與德拉蒙德隊長（Captain Drummond）對話至內容循環。
* [ ] 取得 **肢體動作** 歡呼（Hurrah!）。
* [x] 完成 **成就** 肢體動作大師：肢體動作蒐集齊全。
* [ ] 取得 **武器** 巨人戰士棍棒（Giant Warrior Club）。
* [ ] 取得 **強化素材** 餘燼（Fire Seed）×1。
* [ ] 取得 **道具** 某種化石（Petrified Something）×1。
* [ ] 取得 **道具** 巨人們的靈魂×1。

### 巨人奧洛的記憶（Memory of Orro）

* [ ] 與烏格的班荷特（Benhart of Jugo）對話至內容循環。
* [ ] 取得鋼鐵套裝（Steel Set）。
* [ ] 取得餘燼×1。
* [ ] 取得法洛斯之石×1。
* [ ] 取得愚者的香料×1。
* [ ] 取得不信仰者香料×1。
* [ ] 取得靈魂容器×1。
* [ ] 取得巨人們的靈魂×1。

### 巨人洛的記憶（Memory of Jeigh）

* [ ] 使用國王戒指開啟巨人隕落之森的國王之門。
* [ ] 在前往記憶途中取得光輝楔形石×2。
* [ ] 進入 Memory of Jeigh 後取得餘燼×1。
* [ ] Boss 前優先召喚烏格的班荷特。
    * 班荷特目前有效存活勝利1／3；本戰若存活至Boss結束，可推進為2／3。
    * 德拉蒙德隊長與班荷特在此戰只能二選一召喚。

### Boss：巨人王（Giant Lord）

* 物理：斬擊、打擊、刺擊沒有需要特別換武器的明顯差異。
* 元素：魔法、雷、火皆可使用；闇屬性效果相對較差。
* 異常：可中毒、可出血。
* 近戰：貼近腳踝附近輸出，觀察踩踏與大劍橫掃後反擊。
* 遠程：保持距離時注意巨人王的遠距離劍氣。
* [ ] 讓烏格的班荷特參戰並存活。
* [ ] 擊敗巨人王。
    * [ ] 取得巨人王的靈魂（Giant Lord Soul）。
    * [ ] 取得巨人的共鳴（Giant's Kinship）。
* [ ] 前往記憶末端取得巨人們的靈魂×1。
