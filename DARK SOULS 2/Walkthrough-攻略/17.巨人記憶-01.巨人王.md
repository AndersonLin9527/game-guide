## 區域攻略

* 如蜜 → 巨人隕落之森 → 巨人記憶
* [x] 由如蜜傳送至巨人隕落之森，依序探索三個巨人記憶。
* [x] 確認已持有灰霧核心（Ashen Mist Heart）。
* [x] 巨人們的靈魂（Soul of a Giant）全部保留，不使用。

### 回收：巨人殞落之森—火蜥蜴坑

位於：

* 巨人殞落之森—主塔（Cardinal Tower）→ 往最後的巨人升降梯 → 使用鎔鐵鑰匙（Iron Key）開啟升降梯旁的門
* 巨人殞落之森—主塔（Cardinal Tower）→ 從火點附近的梯子爬下 → 跳下去。
    * 採取採取此路徑，可以先在上方把一隻火蜥蜴用弓射死。
    * 跳下去的時候記得裝備銀貓戒指。
* 火蜥蜴坑內共有4隻火蜥蜴（Flame Salamander）。
* 火蜥蜴完全免疫火屬性； **近戰刺擊效果較佳**，魔法、雷、闇皆可使用。
* [x] 取得 **戒指** 老鷹戒指（Hawk Ring）。
* [x] 取得 **戒指** 火晶石戒指＋1（Flame Quartz Ring +1）。
* [x] 取得 **強化素材** 火龍石（Firedrake Stone）×1。
* [x] 取得 **大盾** 反叛大盾（Rebel's Greatshield）。
* [x] 取得 **鑰匙** 重鐵鑰（Heavy Iron Key）。
    * 反叛大盾與重鐵鑰位於坑內後方右側同一具屍體。
    * 重鐵鑰用於開啟 DLC 鐵之古王的王冠 Crown of the Old Iron King 入口。
* 火蜥蜴可隨機掉落咒術「火球」、「火焰彈」與「大火球」；火球與火焰彈已透過羅莎貝娜取得，不需要在此硬刷。

### 巨人汪姆德的回憶

位於：主塔—與培特初遇的區域

* [x] 與德拉蒙德隊長（Captain Drummond）對話至內容循環。
* [x] 取得 **肢體動作** 歡呼（Hurrah!）。
* [x] 完成 **成就** 肢體動作大師：肢體動作蒐集齊全。
* [x] 取得 **武器** 巨人戰士棍棒（Giant Warrior Club）。
    * 參考 [YouTube Dark Souls 2 - Giant Warrior Club - LOCATION](https://www.youtube.com/watch?v=6eRhzVUgn8E&t=255s)
* [x] 取得 **強化素材** 餘燼×1。
* [x] 取得 **道具** 某種化石（Petrified Something）×1。
* [x] 取得 **道具** 巨人們的靈魂×1。

### 巨人洛的回憶

位於：主塔—先前擊殺咒術者後方

* [x] 與烏格的班荷特（Benhart of Jugo）對話至內容循環。
* [x] 取得 **裝備** 鋼鐵套裝（Steel Set）。
* [x] 取得 **強化素材** 餘燼×1。
* [x] 取得 **道具** 法洛斯之石×1。
* [x] 取得 **道具** 愚者的香料×1。
* [x] 取得 **道具** 不信仰者香料×1。
* [x] 取得 **道具** 靈魂容器×1。
* [x] 取得 **道具** 巨人們的靈魂×1。

### 巨人奧捷的回憶

位於：未知地之處

* [x] 使用國王戒指開啟巨人隕落之森的國王之門。
* [x] 在前往記憶途中取得光輝楔形石×2。
* [x] 進入 巨人奧捷的回憶 後取得餘燼×1。
* [x] Boss 前優先召喚烏格的班荷特。
    * 班荷特目前有效存活勝利1／3；本戰若存活至Boss結束，可推進為2／3。
    * 德拉蒙德隊長與班荷特在此戰只能二選一召喚。

### Boss：巨人王 Giant Lord

| 類型 | 承傷效率 |
|------|---------:|
| 打擊 |     100% |
| 斬擊 |     100% |
| 刺擊 |     100% |
| 魔法 |      70% |
| 雷   |      70% |
| 火   |      70% |
| 闇   |      90% |
| 毒   |      70% |
| 出血 |      70% |

* 物理：斬擊、打擊、刺擊承傷相同，不需要特別更換物理傷害類型。
* 元素：闇屬性承傷效率90%，高於魔法、雷、火的70%；可優先使用黑暗武器（Dark Weapon）附魔。
* 異常：可中毒、可出血。
* 近戰：貼近腳踝附近輸出，觀察踩踏與大劍橫掃後反擊。
* 遠程：保持距離時注意巨人王的遠距離劍氣。
* [x] 讓烏格的班荷特參戰並存活。
* [x] 擊敗巨人王。
    * [x] 取得巨人王的靈魂（Giant Lord Soul）。
    * [x] 取得巨人的共鳴（Giant's Kinship）。
* [x] 前往記憶末端取得巨人們的靈魂×1。

* 使用 **道具** 營火探究者 x 3，重複擊殺巨人王 3 次，同時讓烏格的班荷特參戰且不死。

* 擊敗巨人王後
* 回巨人汪姆德的回憶與 **NPC** 德拉蒙德隊長對話。
    * [x] 取得 **裝備** 衛戍頭盔。
* 回巨人洛的回憶與 **NPC** 烏格的班荷特對話。
    * [x] 取得 **武器** 蒼之大劍、凡荷特的小盾。
    * [x] 取得 **裝備** 凡荷特騎士盔、凡荷特鎧甲、凡荷特手籠、凡荷特靴子。
