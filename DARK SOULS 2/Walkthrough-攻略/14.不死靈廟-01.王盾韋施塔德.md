# DarkSoul 2-Walkthrough-攻略-14.不死靈廟-01.王盾韋施塔德

## 區域攻略

* 不死靈廟入口 → 守墓人亞格藍德
* [x] 從「不死靈廟-入口」火點出發，先完成原罪學者安第爾的入口對話；回答是／否不影響本段全收集。
* [x] 進入有雷蒂雅黑魔女與遊魂的前段房間時， **不要點火把，也不要使用「照明」**。
    * 守墓人亞格藍德厭惡光源；把火把帶進他的房間、使用照明，或讓持火把遊魂追進去，都可能讓他與周圍守墓人敵對。
* [x] 在進入亞格藍德房間前，確認身上沒有啟用中的火把／照明效果。
* [x] 與 **NPC** 守墓人亞格藍德（Grave Warden Agdayne）對話至內容循環。
    * [x] 取得**肢體動作**：求饒（Have Mercy!）**。
    * [x] 先不要攻擊他；他同時是商人，也是本區 Boss 的可召喚 NPC。

* 守墓人亞格藍德 → 死者棄置處
* [x] 從亞格藍德後方繼續前進，處理札因士兵與下層遊魂。
* [x] 在可下落的平台與梯子路線完整探索。
    * [x] 取得 **道具**：靈魂容器（Soul Vessel）。
    * [x] 取得 **道具**：無神眼眸寶珠（Crushed Eye Orb）。
        * 後續可用於如蜜的 **NPC** 林德的莉絮支線，取得全奇蹟相關的重要獎勵；本段只先收集，不急著處理支線。
        * 此道具用於 **NPC**【林德的莉絮】支線。
        * 回到如蜜環堂、靠近莉絮時寶珠會產生反應，可使用寶珠入侵她的世界。
        * 擊敗莉絮可取得全奇蹟收集必要的 **Soothing Sunlight**，以及偶像聖鈴、聖女套裝、環堂鑰石。
        * **目前先不要急著使用**；先確認莉絮商店購買及「集合流亡者」相關條件已完成，再進行支線收尾。
    * [x] 取得 **強化素材**：火種（Fire Seed）×1。
* [x] 搜索有大量墓碑／召喚石的房間。
    * 墓碑被敲鐘後會反覆生成雷蒂雅咒術師；優先找出並破壞召喚石，再慢慢回收道具。
    * [x] 取得 **強化素材**：龍骨化石×1。
    * [x] 取得 **強化素材**：光輝楔形石×1。
    * [x] 取得 **強化素材**：楔形石塊×1。
* [x] 點燃 **火點**：「不死靈廟-死者棄置處」。

* 死者棄置處周邊收集
* [x] 從「死者棄置處」火點回收附近房間的固定收集。
    * [x] 取得 **戒指**：封壞戒指＋2（Bracing Knuckle Ring +2）。
* [x] 遭遇 **NPC闇靈**【無名簒奪者（Nameless Usurper）】時完成擊殺。
* [x] 搜索闇靈路線附近的隱藏牆與鐵寶箱。
    * [x] 取得 **武器**：亞維琳（Avelyn）。
* [x] 完整探索下層墓碑區與側路。
    * [x] 取得 **武器**：無禮者之槌（Mace of the Insolent）。
    * [x] 取得 **法杖**：歐連佛德之杖（Olenford's Staff）。
    * [x] 取得 **奇蹟**：巨雷槍（Great Lightning Spear）。
* [x] 找到通往 Boss 前長廊的捷徑並放下橋梁，之後由「死者棄置處」可較安全地快速回到 Boss 區。

* 王盾韋施塔德 Boss 前
* [x] 在 Boss 前大廳／四個鐵寶箱完整回收固定道具。
    * [x] 取得 **懷念香木×1**。
    * [x] 取得暗夜石等其他固定寶箱內容；一般消耗品不列入本攻略追蹤。
* [x] 若希望 NPC 支援，可召喚 **NPC**【守墓人亞格藍德】。
    * 召喚符位於 Boss 霧門前左側柱子附近；前提是亞格藍德仍存活且沒有敵對。
* [x] 《原罪學者》版亦可召喚 **NPC**【虔誠的史卡蕾特（Devotee Scarlett）】。
    * 召喚符位於前段有兩名雷蒂雅黑魔女的房間柱子附近。
    * 若從「死者棄置處」走捷徑回 Boss，可先召喚她並清掉沿路敵人，避免她在路上消耗過多生命。
* [x] **NPC任務計數確認**：王盾韋施塔德戰 **沒有米勒的露卡提耶爾，也沒有烏格的班荷特召喚符**。
    * 本戰不計入露卡提耶爾3次存活勝利。
    * 本戰不計入班荷特3次存活勝利；目前主進度仍維持班荷特有效存活勝利1／3。

* Boss：王盾-韋施塔德
* [x] 擊敗 **Boss**【王盾-韋施塔德（Velstadt, the Royal Aegis）】。
    * 弱點：**韋施塔德對雷屬性相對較弱**；需要時可使用黃松脂或雷屬性手段提高輸出。
    * 近戰以「等大槌攻擊結束 → 進場1～2刀 → 留精力翻滾」為主，不要貪刀。
    * 第二階段會跪地為聖鈴附加闇屬性並使用闇術；看到蓄力動作時可繞到側後方輸出，但不要在他重新起身時把精力打空。
* [x] 取得 **Boss魂**：王盾韋施塔德的靈魂（Soul of Velstadt）。
* [x] 保留 **Boss魂**：王盾韋施塔德的靈魂；不可捏掉，後續納入 Boss 魂交換盤點。

* Boss 後：汎克拉德與國王戒指
* [x] 擊敗韋施塔德後進入後方圓形房間，看到遊魂狀態的 **汎克拉德（Vendrick）**。
    * **先不要攻擊汎克拉德。** 他是獨立 Boss，建議等巨人靈魂數量準備好後再另開一段攻略處理。
* [x] 從汎克拉德附近屍體取得 **關鍵戒指**：國王戒指（King's Ring）。
    * 國王戒指是後續開啟王之門與推進主線的重要道具。
* [x] 取得國王戒指後返回守墓人亞格藍德並再次對話。
    * [x] 取得 **武器**：暗朧（Darkdrift）。
    * [x] 取得 **防具**：亞格藍德完整套裝。
* [x] 擊敗韋施塔德後確認石頭商人克羅亞娜的新庫存。
    * [x] 可購買楔形石塊×10。
    * [x] 可購買光輝楔形石×3。
    * [x] 可購買龍骨化石×3。
    * [x] 可購買楔形石原盤×1。
    * 商店解鎖只記錄，不強制本段立即購買。
* [x] 返回如蜜確認 **NPC** 賣防具的瑪夫穆藍新庫存。
    * [x] 韋施塔德兜鍪：9800
    * [x] 韋施塔德鎧甲：13000
    * [x] 韋施塔德臂甲：10700
    * [x] 韋施塔德腿甲：12000
* [ ] NG+：再次擊敗王盾韋施塔德。
    * [ ] 取得 **戒指**：國王戰士戒指＋2（Royal Soldier's Ring +2）。
    * [ ] 取得第2份王盾韋施塔德的靈魂。

* 掉落收集
    * 雷蒂雅黑魔女（Leydia Black Witch）掉落收集
        * [x] 暗晶石戒指＋2（Dark Quartz Ring +2）
        * [ ] 黑巫女之杖（Black Witch's Staff）
        * [x] 雷蒂雅黑兜帽
        * [x] 雷蒂雅黑長衣
    * 無禮者（Insolent）
        * 點燃本區域捷徑下方的人形雕像燭台後會出現 **無禮者騎士（Insolent Knight）**。
        * [YouTube Dark Souls II SotFS - Lighting the Undead Crypt](https://www.youtube.com/watch?v=61YDNylrILY)
        * 每個無禮者騎士只能擊殺一次，建議穿上提升掉落的裝備後擊殺。
        * [x] 第二名特定無禮者會掉落 **道具**；懷念香木×1。
        * [x] 無禮者兜鍪（Insolent Helm）。
        * [x] 無禮者鎧甲（Insolent Armor）。
        * [ ] 無禮者手套（Insolent Gloves）。
        * [ ] 無禮者靴子（Insolent Boots）。
        * [x] 無禮者之盾（Shield of the Insolent）。

## 本段完成檢查

* [x] 完成不死靈廟入口至守墓人亞格藍德對話，且沒有因火把／照明讓他敵對。
* [x] 取得**肢體動作**：求饒
* [x] 取得無神眼眸寶珠、靈魂容器、亞維琳、不遜者之槌、歐連佛德之杖、巨雷槍。
* [x] 點燃「死者棄置處」。
* [x] 取得封壞戒指＋2。
* [x] 固定強化素材完成：光輝楔形石×1、龍骨化石×1；另取得火種×1、楔形石塊×1。
* [x] 取得至少1根固定懷念香木；若同時擊殺特定不遜者，可再取得1根。
* [x] 確認王盾韋施塔德戰沒有誤計露卡提耶爾／班荷特任務次數。
* [x] 擊敗王盾-韋施塔德並保留其 Boss 魂。
* [x] **沒有攻擊汎克拉德**，先取得國王戒指。
* [x] 取得國王戒指後回報守墓人亞格藍德，領取暗朧與其完整套裝。
* [x] 記錄韋施塔德後克羅亞娜新增光輝楔形石×3、龍骨化石×3、楔形石原盤×1庫存。

## 完成支線

* 被封者鑰匙 Key to the Embedded
    * 參考 [Walkthrough-攻略-13.阿馬那祭壇-01.歌唱惡魔](./13.阿馬那祭壇-01.歌唱惡魔.md)
    * [x] 返回王都多蘭古雷格中央升降梯塔頂的封閉囚室。
    * [x] 將「被封者鑰匙」作為武器裝備並用於門上的被封者，解救被囚禁的米勒法妮特。
    * [x] 與獲救的米勒法妮特對話，取得 **戒指**：死者戒指（Ring of the Dead）。
    * [x] 返回不死靈廟-不死靈廟．入口回頭走
    * [x] 使用懷念香木解除石化遊魂
    * [x] 點燃 **火點**：不死靈廟-死者棄置處。
    * [x] 取得 **強化素材**：餘燼×1。
    * [x] 取得 **武器**：殺人刀（Manslayer）。

* 無神眼眸寶珠
* [x] 確認 已取得成就「遭棄置的人們」：有許多人聚集在如密。
* [x] 確認 **NPC** 林德的莉絮已完成購買所有武器、戒指、奇蹟。
* [x] 回到如密找到 **NPC** 林德的莉絮，使用**道具**：無神眼眸寶珠（Crushed Eye Orb）。
* [x] 擊殺 **NPC** 林德的莉絮
* [x] 取得 **鑰匙** 環堂鑰石
