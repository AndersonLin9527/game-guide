# DarkSoul 2-Walkthrough-攻略-阿馬那祭壇 01_歌唱惡魔

## 起點與本段目標

* [x] 已從鏡之騎士後方升降梯抵達阿馬那祭壇。
* [x] 已點燃 **火點**：「阿馬那祭壇-祈禱塔」。
* [x] 從「祈禱塔」一路推進至「崩塌遺跡」與「搜索者羅伊絕命之處」。
* [x] 完成本段重要固定收集，特別追蹤 **餘燼**、**光輝楔形石**、**龍骨化石**。
* [x] 完成米勒法妮特（Milfanito）沿途事件，不攻擊任何米勒法妮特。
* [x] 擊敗 **Boss**【歌唱惡魔】並保留Boss魂。
* [x] 取得 **鑰匙**：「被封者鑰匙」（Key to the Embedded），供王都多蘭古雷格塔頂囚室後續事件使用。

### 本區推圖提醒

* 阿馬那祭壇水域會降低移動速度，且水下有阿馬那異形；移動前多用鎖定確認水面與腳下。
* 建議攜帶弓／弩與足量箭矢，優先遠距離處理阿馬那巫女，再逐隻拉近戰敵人；不要一次衝進多名施法者的交叉火線。
* 善用石柱、斷牆遮擋追蹤魔法。火把可以幫助辨認水中落差，但也可能提高部分敵人的索敵範圍。
* 水邊支路很容易直接踩進深水死亡；看到水下道具時先確認可行走的淺水路線，不要直線衝。

## 崩塌遺跡 → 搜索者羅伊絕命之處

* [x] 從「崩塌遺跡」出發，先清掉附近遠距離施法敵人，再探索左側水域。
* [x] 啟動有收藏價值的 **法洛斯機關**；需要法洛斯之石×1。
    * [x] 開啟顯現出的隱藏空間。
    * [x] 取得 **武器**：螺旋槍（Helix Halberd）。
    * 此機關含獨有武器，列為全收集必要機關，不建議略過。

    * [x] 取得 **強化素材**：餘燼×1。

    * [x] 取得 **奇蹟**：陽光之劍（Sunlight Blade）。
* [x] 搜索同區域的水中寶箱。
    * [x] 取得 **咒術**：火焰大風暴（Fire Tempest）。
* [x] 在食人魔附近破壞擋路樹枝，探索後方洞穴。
    * [x] 取得 **防具**：歌手禮服（Singer's Dress）。
    * [x] 取得 **戒指**：生命戒指＋2。
* [x] 記錄本區由龍騎兵守衛的特殊門；目前先不要當作漏收。
    * 後續擊敗汎克拉德並符合開門條件後，再回來取得王的靈魂與國王套裝。
* [ ] 通過下一道霧門，抵達並點燃 **火點**：「阿馬那祭壇-搜索者羅伊絕命之處」。

## 搜索者羅伊絕命之處 → 歌唱惡魔

### NPC召喚

* [x] 若想要一般NPC支援，可在「搜索者羅伊絕命之處」營火附近看到 **NPC**【勇猛的菲麗西亞】（Felicia the Brave）的召喚符。
    * 她可以協助推進至歌唱惡魔並參與Boss戰。
    * 此召喚 **不屬於露卡提耶爾或班荷特任務，不會增加兩人的有效存活勝利次數**。
* [x] 《原罪學者》版另有 **NPC**【孤獨獵人施密特】（Lone Hunter Schmidt）的召喚符，位於本區唯一食人魔附近的小屋內。
    * 他是小白符支援，主要用途是協助清區，持續時間有限；不要把他視為Boss劇情召喚需求。
* [x] **米勒的露卡提耶爾**：本區／歌唱惡魔沒有她的召喚符；目前3／3維持不變。
* [x] **烏格的班荷特**：本區／歌唱惡魔沒有他的召喚符；目前有效存活勝利仍為1／3。

### 固定收集與入侵

* [x] 從營火後的大水域開始，先處理施法者，再進入圓形石柱區回收固定道具。
    * [x] 取得 **武器**：赤鐵雙刃劍（Red Iron Twinblade）。
    * [x] 取得 **強化素材**：龍骨化石×1。
    * [x] 取得 **魔法**：追蹤結晶靈魂塊（Homing Crystal Soulmass）。
* [x] 處理 **NPC暗靈**【Peculiar Kindalur】。
    * 本次掉入深水死亡，未回收隨機掉落。
    * 黑巫女之杖、聖職小盾及相關防具皆有其他取得／刷取來源，不使用營火探究者補刷，留待後期集中收集。
* [x] Boss霧門前找到受傷的 **NPC**【米勒法妮特】，與她互動完成本段事件；不要攻擊她。
* [x] 清乾淨霧門前與召喚路線，補滿元素瓶後再進Boss戰。

## Boss：歌唱惡魔

### 戰前確認

* [x] 本戰 **不需要** 為露卡提耶爾或班荷特任務強制召喚NPC。
* [x] 若使用菲麗西亞支援，確認自己為活人狀態並在「搜索者羅伊絕命之處」附近召喚。
* [x] 不為了本戰使用營火探究者。

### 戰鬥重點

* 歌唱惡魔縮在外殼裡時，外殼幾乎不吃傷害；不要浪費精力硬砍外殼。
* 等牠打開外殼、露出頭部與手臂後再輸出；以「躲一輪攻擊 → 砍1～2下 → 拉開」為主。
* 牠站立準備向前撲或連續揮擊時，不要貪刀；優先翻滾至側面或後方。
* 使用巨劍時避免一次把精力打空，至少保留一次翻滾的精力。

### 擊敗後

* [x] 擊敗 **Boss**【歌唱惡魔】。
* [x] 取得並保留 **Boss魂**：歌唱惡魔的靈魂；不可捏掉，後續納入Boss魂交換盤點。
* [x] 取得 **鑰匙**：被封者鑰匙（Key to the Embedded）。
* [x] Boss進度完成後再同步更新總表；本段不自行預先勾選。
* [x] 班荷特有效存活勝利仍為1／3；露卡提耶爾仍為3／3，不因本Boss改動。

## Boss後：死者之塔與米勒法妮特後續

> **《原罪學者》版本提醒：** 歌唱惡魔後方通往「死者之塔」的支路入口被石化遊魂擋住，需要1根懷念香木解除。主進度文件目前記錄懷念香木為0，因此如果此時仍沒有香木，先記錄回收點即可，不要卡在這裡；可以先繼續主線前往不死靈廟。

* [x] 歌唱惡魔後沿洞穴前進，在通往不死靈廟的主路旁確認「死者之塔」支路位置。
* [ ] 若已有懷念香木：解除入口石化遊魂。
    * [ ] 點燃 **火點**：「阿馬那祭壇-死者之塔」。
    * [ ] 取得 **強化素材**：餘燼×1。
    * [ ] 取得 **武器**：殺人刀（Manslayer）。
* [ ] 若目前仍為0根懷念香木：本段標記為「待回收」，先前往不死靈廟；取得下一根香木後再傳送回來完成。

### 被封者鑰匙後續

* [x] 返回王都多蘭古雷格中央升降梯塔頂的封閉囚室。
* [x] 將「被封者鑰匙」作為武器裝備並用於門上的被封者，解救被囚禁的米勒法妮特。
* [x] 與獲救的米勒法妮特對話，取得 **戒指**：死者戒指（Ring of the Dead）。
* [ ] 後續回到阿馬那祭壇「死者之塔」上方的祈禱處，完成米勒法妮特相關對話與獎勵盤點。
* [ ] 米勒法妮特事件可能提供額外 **餘燼** 獎勵；取得時另計，不和本區固定拾取的餘燼×2混在一起。
