## 區域攻略

* 安第爾之館－守護龍 → 衛龍巢穴
* [x] 擊敗安第爾之館的守護龍後搭乘升降梯，正式進入 **衛龍巢穴（Dragon Aerie）**。
* [x] 在入口懸崖找到 **NPC**【綠衣巡使（Emerald Herald）】，對話至內容循環。
    * [x] 取得 **重要道具**：老舊羽毛（Aged Feather）。
    * 老舊羽毛可無限次使用，效果等同返骨片，返回最後休息的火點且不消耗道具。
    * 這也是宮廷魔法師納瓦藍第4項暗殺委託的證明道具； **只要持有即可完成委託，不需要殺綠衣巡使，也不會被納瓦藍收走。**
* [x] 點燃 **火點**：「衛龍巢穴－衛龍巢穴（Dragon Aerie）」。

* 衛龍巢穴探索規則
* [x] **不要隨意打破龍蛋。**
    * 原罪學者版的3隻守護龍平時會睡著；攻擊守護龍、在牠附近打破龍蛋，或穿著月下蝶套裝太靠近，都可能把牠喚醒。
    * 最後通往龍祭壇的長吊橋會被飛龍破壞；破壞越多龍蛋，安全通過的時間越短。
* [x] 本區共有大量晶蜥，優先使用遠程攻擊、範圍魔法或預判逃跑路線處理。
    * 本區共有11隻晶蜥；其中多隻會掉落光輝楔形石、龍骨化石與其他高階強化素材。
    * 晶蜥若失手逃掉，可休息火點重置；不需要使用營火探究者。
* [x] 若走完整支線路線，在木橋區處理 **NPC闇靈**【劍士莎倫（Fencer Sharron）】。
    * 她是原罪學者版新增的入侵者，不是Boss，也沒有任務召喚計數。
* [x] 若先前錯誤釋放納瓦藍，他可能在衛龍巢穴入侵；目前正確全收集路線維持納瓦藍被囚禁，因此正常情況不應遇到此入侵。

* 第一座龍巢
* [x] 先清理爆炸遊魂與晶蜥，盡量不要讓自己的攻擊波及龍蛋。
* [x] 取得 **武器**：龍之牙（Dragon Tooth）。
* [x] 若要全收集3隻守護龍的原罪學者版固定掉落，再主動喚醒並擊敗第1隻 **守護龍（Guardian Dragon）**。
    * [x] 取得 **戒指**：火晶石戒指＋2（Flame Quartz Ring +2）。
    * 本區守護龍是強敵／小Boss型敵人， **不另外計入Boss總數**。
    * **物理傷害**：斬擊、打擊、刺擊沒有值得為此換武器的明顯差距。
    * **屬性**：魔法較有效；雷也可用。火抗性高，不建議主打火傷。
    * **異常**：可中毒，可用毒箭等方式降低近身風險。

* 第二座龍巢
* [x] 沿路回收晶蜥的高階強化素材。
* [x] 在第二隻守護龍之前、龍蛋附近取得 **強化素材**：龍骨化石×1。
    * 不要用大範圍攻擊亂掃龍蛋；需要戰鬥時先把敵人引離蛋區。
* [x] 擊敗第2隻守護龍。
    * [x] 取得 **咒術**：火焰風暴（Fire Tempest）。
    * 原罪學者版此掉落為保證取得，不要混用初版的隨機掉落資料。

* 第三座龍巢
* [x] 處理最後一批晶蜥與爆炸遊魂。
* [x] 取得 **戒指**：邪眼戒指＋1（Ring of the Evil Eye +1）。
* [x] 擊敗第3隻守護龍。
    * [x] 取得 **強化素材**：光輝楔形石×1。
    * [x] 取得 **強化素材**：龍骨化石×1。
    * [x] 取得 **道具**：某種化石（Petrified Something）×1。
    * 原罪學者版以上3項為第3隻守護龍的保證掉落。

* 滑索與隱藏素材
* [x] 利用滑索探索火點上方及側邊平台。
    * [x] 在滑索可抵達／跳落的平台取得 **強化素材**：光輝楔形石×1。
    * 部分平台是單向落點，拿完後直接使用老舊羽毛回到火點即可。
* [x] 探索完3座龍巢後，沿長吊橋快速前進，進入下一區 **龍祭壇（Dragon Shrine）**。
    * 不要在長吊橋上停留整理裝備或撿選單；飛龍會直接破壞吊橋。

* 龍祭壇入口與安第爾
* [x] 點燃 **火點**：「龍祭壇－祭壇．入口（Shrine Entrance）」。
* [x] 若安第爾在此火點出現，與 **安第爾（Aldia）** 對話至消失。
    * 對話的「是／否」選項不影響日後安第爾Boss是否出現；真正重要的是完成三次安第爾遭遇，並在最終戰前擊敗汎克拉德王。
    * 為全Boss／完整結局路線，不要漏掉本次龍祭壇對話。

* 原罪學者版龍騎士「決鬥規則」
* [x] 龍祭壇中的金色 **龍騎士（Dragon Knight）** 大多會向玩家敬禮而不主動攻擊，這不是Bug。
* [x] 每一段先正面擊敗大型 **龍衛（Drakekeeper）**，再往前走。
    * 不要直接跑過龍衛；逃避決鬥會使該區龍騎士群轉為敵對。
    * 不要主動攻擊向你敬禮的龍騎士。
    * 為避免破壞決鬥規則，探索階段先不要召喚其他玩家；要打古龍時再考慮Boss前召喚。
* [x] 最後大階梯上的雙持大劍龍騎士會主動攻擊，而且不重生；正常擊敗他後再繼續前進。

* 龍祭壇固定收集
* [x] 使用法洛斯機關取得 **套裝**：罪之面罩、罪之長衣、罪之袖套、罪之緊身褲。
* [x] 取得 **強化素材**：光輝楔形石×1。
* [x] 取得 **武器**：札因大斧（Drakekeeper's Greataxe）。
* [x] 取得 **盾牌**：札因大盾（Drakekeeper's Greatshield）。
* [x] 取得 **強化素材**：楔形石原盤×1。
* [x] 取得 **戒指**：三龍戒指（Third Dragon Ring）。
    * 這是本周目全戒指的重要固定收集，不要漏拿。
* [x] 在高塔遭遇並擊敗 **NPC闇靈**【龍牙威亞德（Dragonfang Villard）】。
* [x] 取得 **重要道具**：化石蛋（Petrified Egg）。
    * [x] 之後交給熔鐵城的行商人馬格赫拉德，可加入古龍後裔誓約；交出去是正確用途，不會失去全收集進度。
* [x] 取得 **盾牌**：衛龍盾（Watchdragon Parma）。
    * 此盾有提升掉寶率的特殊效果，可納入日後刷裝備配置。
* [x] 從化石蛋區往下方平台落下，開啟寶箱。
    * [x] 取得 **魔法**：結晶魔法武器（Crystal Magic Weapon）。
    * [x] 取得 **道具**：懷念香木×1。

* 古龍前：先對話，不要一見面就砍
* [x] 抵達龍祭壇最上層，找到 **NPC／可選Boss**【古龍（Ancient Dragon）】。
* [x] **第一次到達時先對話，不要攻擊。**
* [x] 取得 **重要道具**：灰霧核心（Ashen Mist Heart）。
    * 灰霧核心可進入巨人與龍的記憶，是後續巨人王、古龍的靈魂等收集的必要道具。
    * 取得灰霧核心本身就完成龍祭壇的主線目的；古龍戰不是推進主線的必要Boss。

* Boss：古龍（可選）
* 本戰 **沒有米勒的魯卡提耶或烏格的班荷特召喚符**，不增加兩人的任務存活勝利次數。
* 古龍戰可使用的NPC召喚包含：
    * **溫格之首（Head of Vengarl）**：完成其相關進度後可用。
    * **屠夫梅琳達（Melinda the Butcher）**：先前擊敗她的入侵版本後可用。
    * **害羞的雷（Bashful Ray）**：原罪學者版限定，小白符召喚。
* 古龍血量很高，而NPC很容易被大範圍火焰秒殺；若目的是穩定擊殺，通常單挑比帶NPC更容易控制Boss動作。
* [x] 若本階段要推進「全Boss」目標，在取得灰霧核心後再攻擊古龍並進入Boss戰。
    * 若目前只想推主線，可以先保留古龍，之後在挑戰汎克拉德王前回來擊殺即可。
    * **物理弱點**：斬擊、打擊、刺擊效果相同，沒有「特別怕刺」或「特別怕砍」。
    * **屬性弱點**：沒有明顯的元素弱點；火抗性極高， **最不推薦火屬性**。魔法、雷、闇可正常使用，但不算特別脆弱。
    * **異常狀態**：可中毒、可出血；但Boss血量很高，異常只適合作為額外傷害。
    * 近戰最穩定的打法是貼住後腳腳趾附近輸出；看到抬腳就閃避踩踏，再移動到另一隻後腳，反覆控制Boss只使用踩踏與少量飛空攻擊。
    * 若古龍起飛，立刻往尾巴方向全力衝刺離開落火範圍，不要貪刀，也不要停在場地中央鎖定抬頭看。
    * 可使用火晶石戒指＋2、劇烈出汗等方式提高火防；古龍的火焰傷害非常高，火防能大幅增加容錯。
    * 戰鬥時間長，建議攜帶修理光粉或準備第二把已強化武器，避免主武器耐久耗盡。
* [x] 擊敗古龍後取得：
    * [x] **巨人們的靈魂（Soul of a Giant）**×1。
    * [x] **強化素材**：龍骨化石×1。
    * **古龍不會掉落「古龍的靈魂」。**古龍的靈魂要在取得灰霧核心後，前往輝石鎮蓋多勒夫雷迪亞Boss房的龍之記憶取得。

## 後續追蹤

### 支線任務-NPC 宮廷魔法師納瓦藍暗殺任務

* [ ] 取得老舊羽毛後，返回安第爾之館，以遊魂狀態隔著結界與 **宮廷魔法師納瓦藍** 對話。
* [ ] 依序完成尚未完成的委託；不能跳過中間任務直接交老舊羽毛。
    * [ ] 第2項：出示凱爾的頭盔，取得愚者的香料。
    * [ ] 第3項：出示日暮之杖，取得咒術「禁忌太陽」。
    * [ ] 第4項：出示老舊羽毛，取得魔法「解放魔力（Unleash Magic）」。
* [ ] 完成全部委託後確認納瓦藍商店與混沌完整套裝等獎勵； **全程不需要拉動釋放納瓦藍的拉桿。**

### 誓約-古龍後裔

* [x] 將龍祭壇取得的 **化石蛋（Petrified Egg）** 交給熔鐵城的 **NPC** 拉．卡納爾的馬格赫拉德**。
* [x] 加入 **古龍鱗片（Dragon Remnants）** 誓約。
    * [x] 取得 **戒指**：古龍徽記（Ancient Dragon Seal）。
    * [x] 取得 **多人道具**：古龍眼珠（Dragon Eye）。
* 化石蛋的主要用途就是開啟此誓約，可以安全交給馬格赫拉德。
* 古龍眼珠可以在地面留下特殊召喚印記，讓其他玩家把你召喚過去進行 PvP 決鬥，如果你贏了，會取得龍鱗（Dragon Scale），龍鱗就是這個誓約升級需要的素材。

### 古龍的靈魂與龍之記憶

* [x] 取得灰霧核心後回到 **輝石鎮蓋多勒－公爵的夫雷迪亞Boss房**。
* [x] 對場地中的古龍遺骸使用灰霧核心，進入 **龍之記憶（Dragon Memories）**。
* [x] 取得 **Boss魂**：古龍的靈魂（Ancient Dragon Soul）。
    * 古龍的靈魂與龍祭壇活著的古龍是兩個不同取得機制；擊殺龍祭壇古龍不會掉這顆魂。
    * [ ] 向 **NPC** 賣武器的歐尼菲克斯以古龍的靈魂交換 **龍之大曲劍（Curved Dragon Greatsword）**。

### 掉落收集-龍祭壇—龍衛兵

* 龍祭壇的龍衛兵（Drakekeeper）隨機掉落： (大隻會主動攻擊的)
    * [x] 衛兵兜鍪。
    * [x] 衛兵鎧甲。
    * [x] 衛兵臂甲。
    * [x] 衛兵腿甲。
    * [ ] 札因直劍（Drakekeeper's Sword）。
    * [x] 札因的盾（Drakekeeper's Shield）。

    * [x] 榮譽大盾（Greatshield of Glory）。
    * 札因大斧與札因大盾已有固定寶箱，不需要靠刷怪取得。

### 掉落收集-龍祭壇—黑龍騎士
