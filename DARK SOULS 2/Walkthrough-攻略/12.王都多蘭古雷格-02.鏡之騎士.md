# DarkSoul 2-Walkthrough-攻略-12.王都多蘭古雷格-02.鏡之騎士

## 王城後半

* [x] 啟動 **機關**：將敵人引至巨人石像附近擊殺，啟動中央升降梯。
* [x] 取得 **魔法**：靈魂大劍（Soul Greatsword）；位於長梯上方、巨人機關附近房間的寶箱。
* [x] 取得 **聖鈴**：夸特之鈴（Caitha's Chime）；位於長梯上方、巨人機關附近房間的寶箱。
* [x] 取得 **武器**：古老騎士大鎚（Old Knight Hammer）；王城後半寶箱。
* [x] 提示 活人狀態下可以召喚 **NPC**【傭兵魯特】（Sellsword Luet），協助擊敗樓梯大廳的馬怪。
* [x] 取得 **戒指**：戈達守護戒指（Gower's Ring of Protection）；擊敗樓梯大廳的馬怪後拾取。
* [x] 取得 **咒術**：火焰風暴（Firestorm）；樓梯上方、古老騎士守護的寶箱。
* [x] 取得 **武器**：晾衣長刀（Washing Pole）；處理同段寶箱怪後拾取。
* [x] 取得 **強化素材**：龍骨化石；同段寶箱怪掉落。
* [x] 取得 **道具**：元素碎片；探索後半通往營火捷徑的支路寶箱。
* [x] 開啟返回「王城中層」的捷徑。
* [x] 回如蜜交付元素碎片，確認元素瓶升至12瓶+5。

## 中央升降梯塔頂

* [x] 取得 **鑰匙**：王之迴廊鑰匙（Key to King's Passage）。
* [x] 取得 **魔法**：強力法術盾（Strong Magic Shield）。
* [x] 取得 **道具**：靈魂容器。
* [x] 取得 **強化素材**：火種。
* [x] 記錄塔頂被拘束人形與封閉房間的位置；後續取得對應鑰匙後再回來。
* [x] 搭乘升降梯下樓，使用王之迴廊鑰匙開門。

### 王之迴廊與鏡之騎士

* [x] 收取王之迴廊兩側屍體上的道具。
* [x] 清除霧門前會活動的石像敵人。
* [x] 恢復活人狀態
    * [x] 召喚 **NPC**【烏格的班荷特】。
    * [x] 提示 可額外召喚 **NPC**【灰之騎士博依德】（Ashen Knight Boyd），召喚符位於霧門前右側、稍微後方的柱子附近。
* [x] 擊敗 **Boss**【鏡之騎士】。
* [x] 確認班荷特在Boss死亡時仍然存活；成功後將有效存活勝利更新為1／3。
* [x] 取得並保留**Boss魂**：鏡之騎士的靈魂。

### 鏡之騎士後方寶箱

* [x] 取得 **魔法**：靈魂閃光（Soul Bolt）。
* [x] 取得 **戒指**：法術晶石戒指＋2（Spell Quartz Ring +2）。
* [x] 取得 **道具**：營火探究者×3；僅收集，暫時不使用。
* [x] 搭乘後方升降梯，抵達阿馬那祭壇。
* [x] 點燃 **火點**：「阿馬那祭壇-祈禱塔」營火。
