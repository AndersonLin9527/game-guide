## 區域攻略

* 起點：如密。
* 本段目標：進入DLC2「鐵之古王的王冠」，完整探索黑霧之塔主路線，取得榮華大劍、固定光輝楔形石×6、龍骨化石×10，並擊敗煙之騎士。
* 米勒的魯卡提耶與烏格的班荷特任務均已完成；本段的召喚NPC不增加兩人的任務次數。
* 黑霧之塔是垂直多層地圖。先取得高熱鐵棒並啟動中央電梯，再回收早先無法到達的平台與房間。

### 如密出發與重鐵鑰

* [x] 在如密整理裝備、修理武器並補滿遠程彈藥。
* [x] 檢查重要道具欄是否已有重鐵鑰（Heavy Iron Key）。
* 若尚未取得：
    * [x] 傳送 **火點** 巨人隕落之森－主塔。
    * [x] 前往最後的巨人附近、火蜥蜴所在的洞窟。
    * [x] 回收洞窟內的重鐵鑰。
    * 火蜥蜴火焰傷害高；可從已開放的正式入口進入，不必冒險從高處硬摔。
* [x] 確認重鐵鑰已在重要道具欄。

### 進入鐵之古王的王冠

* [x] 傳送 **火點** 鎔鐵城－艾吉爾鐵像，跑到鐵之古王（尾王）後方找到 DLC2 祭壇。
* [x] 傳送到 DLC2 入口。
* [x] 搭乘升降台，使用重鐵鑰開啟大門。
* [x] 穿過霧門並沿巨型鎖鏈前往黑霧之塔。
* [x] 點燃 **火點** 黑霧之塔－王座之階（Throne Floor）。

### 黑霧之塔頂層與鎔鐵之楔

* [x] 取得 **關鍵道具** 鎔鐵之楔×6。
    * 鎔鐵之楔是有限道具，用來破壞煤炭之像；每破壞 1 座，可取得 1 個「煤炭」娜德拉的靈魂碎片。
    * 擊殺煙之騎士前至少保留 4 個；Boss 場外有 4 座會替 Boss 快速回血的煤炭之像，開戰前應優先破壞。
    * 本周目共有11個鎔鐵之楔：初次進入黑霧之塔取得 6 個、啟動電梯後取得 4 個、擊敗騎士亞倫後從其後方王座取得最後1個。
    * 黑霧之塔共有11座煤炭之像；煙之騎士另會掉落1個靈魂碎片，合計12個。
    * 集齊12個碎片後，會自動組成完整的「煤炭」娜德拉的靈魂。
    * 完整的「煤炭」娜德拉的靈魂可交換聖鈴「吶喊之鈴」或咒術「咆哮」；兩者各需1份，因此全收集需要跨周目。
* 第一座煤炭之像建議保留；擊敗騎士亞倫並取得最後 1 個鎔鐵之楔後，再回來破壞。
* [x] 取得 **戒指** 敏捷戒指：從第一座煤炭之像後方樓梯下方。

### 王座之階至上層

* [x] 依序下降圓形平台與灰燼區，逐批引出煤炭戰士，避免被包圍。
* 梯子區
    * [x] 取得 **武器** 鐮刀＋7。
    * [x] 取得 **道具** 七色石×10。
* [x] 取得 **強化素材** 楔形石原盤：金屬寶箱。
* [x] 煤炭之像與多名煤炭戰士的大房間：先破壞能強化／治療敵人的煤炭之像，再清理敵人。
* [x] 取得 **咒術** 舞蹈之火（Dance of Fire）：右側小房。
* 拉動拉桿開啟大門。
* [x] 發現隱藏牆壁
    * [x] 取得 **道具** 靈魂容器×2、古老輝滴石×4、枯萎黃昏草×4。
* 裝滿炸藥桶的敵人可用弓箭、火焰壺或引誘方式引爆；不要近身和鐵戰士同時混戰。
* [x] 取得 **武器** 護手帶＋8（Caestus）：木寶箱。
* [x] 點燃 **火點** 黑霧之塔－上層（Upper Floor）。
* [x] 取得 **戒指** 火晶石戒指＋3。
* [x] 取得 **強化素材** 光輝楔形石×2。
* 灰燼平台的可破壞灰像中回收多種大型靈魂。

### 暗殺者馬雷達與榮華大劍

* [x] 從上層通往側塔的鎖鏈時，觸發 **入侵 NPC** 暗殺者馬雷達（Maldron the Assassin）。
    * 馬雷達受傷後會向塔底逃跑，並試圖把玩家帶進詛咒與敵群；不要盲目追下去。
    * 建議先把沿路敵人與煤炭之像處理好，再逐層壓縮他的逃跑路線。
* [x] 取得 **道具** 營火探究者×2：塔頂金屬寶箱。
* [x] 取得 **道具** 銀色護符×5。
* [x] 取得 **武器** 亞倫大弓＋5：中央柱平台。
* [x] 取得 **質變素材** 蒼光石×2：側塔底部。
* [x] 取得 **武器** 榮華大劍：側塔底部寶箱。
    * 榮華大劍使用光輝楔形石強化，最高可強化至＋5，共需15個。
    * 需求為力氣25、敏捷25、智力20、信仰20。
    * 置於左手時具有特殊動作模組及較高的能力補正。
    * 無法使用松脂或法術附魔。

### Boss：煙之騎士 Fume Knight

#### 可召喚 NPC

* [x] 鋼之艾莉（Steelheart Ellie）。
* [x] 晦冥的卡里昂（Carhillion of the Fold）。
* 兩位 NPC 都不屬於需要靠 Boss 存活勝利推進的任務，本戰召喚與否不影響NPC支線完成度。
* 召喚 NPC 會提高 Boss 強度，而且兩名 NPC 不擅長迴避；若召喚後更難打，建議單人挑戰會比較簡單。

#### 弱點與抗性

| 類型 | 承傷效率 |
|------|---------:|
| 打擊 |     100% |
| 斬擊 |     100% |
| 刺擊 |     100% |
| 魔法 |      63% |
| 雷   |      63% |
| 火   |      21% |
| 闇   |      63% |
| 毒   |     免疫 |
| 出血 |     免疫 |

* **黑暗武器提醒：** 闇屬性並非完全無效，但承傷效率只有63%，不能視為煙之騎士的弱點。
* 魔法、雷與闇的承傷效率同為63%；選擇附魔時應依武器面板、角色補正與可用法術決定，雷並非煙之騎士的特殊弱點。
* 若武器本身的物理攻擊較高，優先維持穩定的物理傷害。
* **不要使用火焰武器、焦炭松脂或火系咒術作為主力**；煙之騎士的火焰承傷效率只有21%。

#### 第一階段

* 煙之騎士同時使用煙之劍與煙之特大劍。
* 煙之劍攻擊出手較快，煙之特大劍攻擊較慢，且經常作為連段終結。
* 看到特大劍慢揮並確認收招後再反擊；每次以攻擊1下為基準，不要預設連段已經結束。
* 裝備負重保持較低，並隨時保留至少一次翻滾所需的精力。
* 盾牌可以應急抵擋煙之劍，但煙之特大劍會大量削減精力，主要防禦方式仍應以翻滾為主。

#### 第二階段

* Boss剩餘約60%生命時，會丟棄煙之劍，並為煙之特大劍附加火＋闇力量。
* 轉入第二階段的附魔動作期間可以輸出；附魔動作結束後常接大範圍慢速橫掃，不可貪刀。
* 慢速火焰橫掃：朝Boss及劍身方向斜前翻滾，穿過攻擊後只反擊1次。
* 插劍爆炸＋旋轉火球：先離開近身爆炸範圍，再從火球之間的空隙穿過；完全避開爆炸與火球後，才是較安全的喝元素瓶時機。
* 奔跑突刺／跳劈：向側邊翻滾避開後，可反擊1次。
* 第二階段的連段可能臨時追加攻擊；未確認Boss完全收招前，不要連續輸出。

#### 特殊注意

* 裝備韋施塔德兜鍪進入Boss場地，會使煙之騎士立即進入特大劍強化狀態；一般攻略不建議這樣做。
* 召喚NPC會提高Boss的生命與抗性，而且兩名NPC都不擅長迴避；若召喚後反而更難戰鬥，建議改為單人挑戰。
