## 攻略順序

1. 先從黑霧之塔－中心部前往鐵之迴廊，擊敗鎔鐵惡魔（藍色）。
2. 再從黑霧之塔－中心部前往鎔鐵王座，進入鐵之古王的記憶並擊敗騎士亞倫。
3. 取得騎士亞倫後方王座的最後 1 個鎔鐵之楔，完成「煤炭」娜德拉的靈魂。

* 起點：**火點** 黑霧之塔－中心部（Foyer）。
* 進入鐵之迴廊前必須持有塔之鑰匙，並已用高熱鐵棒啟動中央電梯。
* 進入鐵之古王的記憶前必須持有灰霧核心與鐵之古王的王冠，也就是必須先擊敗煙之騎士。
* 兩個區域都沒有固定的光輝楔形石或龍骨化石。

## 第一段：鐵之迴廊與鎔鐵惡魔（藍色）

### 中心部至鐵之迴廊入口

* [ ] 傳送至 **火點** 黑霧之塔－中心部。
* [ ] 搭乘中心部附近向下的電梯。
* [ ] 使用塔之鑰匙開啟下層的小型鐵門。
* [ ] 沿兩段樓梯向下，搭乘下一座電梯下降。
* [ ] 進入鐵之迴廊，點燃 **火點** 鐵之迴廊－入口（Iron Hallway Entrance）。
* 鐵之迴廊沒有入侵 NPC。
* 本區敵人包含灰燼戰士、鐵戰士、虛鎧（Possessed Armor）、煙之術師（Fume Sorcerer）與星占術師。
* 建議準備遠程武器、毒箭、修理光粉與魔法抗性裝備；這段跑王路線比 Boss 本身更容易消耗補給。

### 鐵之迴廊召喚 NPC

* [ ] 不屈的洛麗（Steel-willed Lorrie）。
* [ ] 流浪劍士艾多爾（Drifter Swordsman Aidel）。
* 兩個召喚記號都在入口附近的召喚石像區。
* 兩位 NPC 都不涉及需要靠 Boss 存活勝利推進的支線，本戰召喚與否不影響 NPC 任務完成度。
* 若要召喚 NPC 協助清路，建議走下層穩定路線；NPC 容易被限時鐵門隔開。
* 召喚 NPC 會提高 Boss 的生命與抗性。若已能穩定通過跑王路線，單人挑戰通常較容易控制 Boss 節奏。

### 第一限時鐵門

* [ ] 從火點前進至第一個拉桿房。
* 拉下拉桿後，前方鐵門只會開啟約 8 秒；要走上層捷徑就必須立刻衝刺。
* 若沒有成功通過，不要在鐵門前硬闖敵群；改從左側缺口跳下，走下層穩定路線。
* 上層限時路線：
    * [ ] 第一段牢房右側第 3 間取得 **強化素材** 楔形石大碎片×7。
    * [ ] 通過第一道限時鐵門後，在低處平台取得 **道具** 深紅的水×2。
* 下層穩定路線：
    * 逐批引出灰燼戰士與鐵戰士，優先處理高處煙之術師與星占術師。
    * 可用弓箭或毒箭先處理無法直接接近的施法敵人。
    * 不建議全程硬跑；緩速法術、雷槍與弓箭容易在狹窄通道內連續命中。

### 第二限時鐵門至 Boss 霧門

* [ ] 抵達第二個拉桿房。
* 第二道鐵門同樣只開啟約 8 秒；拉動拉桿時附近會出現煙之術師，先確認精力與路線。
* [ ] 第二段牢房區取得：
    * [ ] **香料** 愚者的香料×1。
    * [ ] **道具** 火把×5。
* [ ] 通往 Boss 前的側邊平台取得 **道具** 枯萎的黃昏草×2。
* [ ] 在 Boss 前房間回收：
    * [ ] **香油** 古樹香油×3。
    * [ ] **道具** 龜裂血紅眼眸寶珠×3。
    * [ ] **道具** 乾縮草根×1。
* Boss 前房間有虛鎧與鐵戰士；先清敵再換裝、附魔及補血。
* 若召喚 NPC，兩位 NPC 可能自行改走下層路線；不要為了等他們停留在遠程火力交叉處。

### Boss：鎔鐵惡魔（藍色） Blue Smelter Demon

#### 弱點與抗性

| 類型 | 判定 |
|------|------|
| 打擊 | 弱點 |
| 斬擊 | 抗性較高 |
| 刺擊 | 未列為弱點 |
| 魔法 | 高抗性 |
| 雷   | 中等抗性 |
| 火   | 中等抗性 |
| 闇   | 中等抗性，元素中相對有效 |
| 毒   | 有效 |
| 出血 | 不建議 |

* 優先使用打擊武器；斬擊武器的效果較差。
* **黑暗武器提醒：** 本 Boss 並非不適合闇屬性。闇抗性低於魔法抗性，黑暗武器可以使用，但仍應以武器本身的物理傷害與打擊屬性為主。
* 魔法抗性非常高，不建議以魔法武器或靈魂魔法作為主力。
* Boss 的藍色火焰實際造成魔法傷害；應裝備法術晶石戒指＋3、周天魔戒指＋1 或其他魔法抗性裝備，不要誤堆火焰抗性。
* 毒可以生效；毒箭、毒飛刀或毒霧能協助削血。

#### 戰鬥階段與應對

* 第一階段以物理劍擊為主，招式和鎔鐵城的鎔鐵惡魔相似，但部分揮劍會故意延遲。
* 第一度強化後，Boss 身體周圍會持續造成魔法傷害；近戰不要長時間貼身。
* 第二度強化後，劍身附加大量魔法傷害，攻擊距離也會變長。
* 建議貼近 Boss 左側腰部，也就是玩家畫面的右側繞行；看到攻擊再向右側翻滾。
* 下劈插劍後可能接範圍魔法爆炸；先確認是否爆炸，再進場反擊。
* 每次反擊以 1 下為基準，至少保留可連續翻滾 2～3 次的精力。
* 喝元素瓶應等 Boss 完整收招、跳劈爆炸結束或距離已充分拉開後再使用。

#### 特殊注意

* 藍色鎔鐵惡魔的出手延遲和鎔鐵城版本不同，不要完全依照紅色版本的節奏提前翻滾。
* 召喚兩位 NPC 適合遠程或毒箭打法；近戰若發現 Boss 血量與抗性提高後更難處理，建議改為單人挑戰。
* [ ] 擊敗鎔鐵惡魔（藍色）。
    * [ ] 取得 **Boss 魂** 鎔鐵惡魔的靈魂。

### 鎔鐵惡魔戰後回收

* [ ] 離開 Boss 場地前，在後方區域取得 **裝備** 法洛斯面具。
* 法洛斯面具會持續讓角色處於濕身狀態，提高火焰抗性並降低雷抗性；也能洗掉身上的油與部分附著效果。
* [ ] 使用老舊羽毛返回火點，準備第二段騎士亞倫路線。

## 第二段：鐵之古王的記憶與騎士亞倫

### 中心部至鎔鐵王座

* [ ] 傳送至 **火點** 黑霧之塔－中心部。
* [ ] 從中心部走入主室，進入左側通道；經過牛頭機關後，搭乘右側第一座向上的電梯。
* [ ] 抵達上層後，等待右側的小型升降台並繼續向上。
* [ ] 面向牆壁離開升降台後向左走，使用塔之鑰匙開啟鐵門。
* [ ] 通過鐵門後搭乘下一座電梯向上。
* [ ] 抵達上層後處理左側的煤炭之像。
    * 若目前仍持有 2 個鎔鐵之楔與 9 個「煤炭」娜德拉的靈魂碎片，可在此使用 1 個鎔鐵之楔，取得第 10 個碎片。
    * 煤炭之像會治療附近敵人，建議在處理徘徊者前先破壞。
* [ ] 觸發 **入侵 NPC** 徘徊者（Prowlers）集團。
    * 不要一次衝入敵群；退回升降台或利用樓梯逐一引出。
    * 若先衝上樓點燃火點，之後可從較安全的位置分批清理。
* [ ] 點燃 **火點** 黑霧之塔－鎔鐵王座（The Smelter Throne）。
* [ ] 依目前進度，先回查黑霧之塔另一座尚未破壞的煤炭之像，使用剩餘 1 個鎔鐵之楔，使「煤炭」娜德拉的靈魂碎片增至 11 個。
    * 尚未破壞的煤炭之像位置取決於先前探索路線；可依本文末尾的 11 座煤炭之像影片逐一核對。
    * 完成後返回 **火點** 黑霧之塔－鎔鐵王座，再進入鐵之古王的記憶。

### 鐵之古王的記憶入口

* [ ] 確認身上持有灰霧核心與鐵之古王的王冠。
* [ ] 調查鎔鐵王座火點前方、散發紅光的騎士亞倫盔甲，進入鐵之古王的記憶。
* 鐵之古王的記憶內沒有火點；死亡後需從鎔鐵王座重新進入。
* 進入記憶後會開始約 18 分鐘的停留限制；進入 Boss 戰後計時停止。
* [ ] 進入記憶後，在召喚石像附近確認兩位可召喚 NPC 的召喚記號。
* 記憶內沒有入侵 NPC。
* 敵人以亞倫騎士、亞倫騎士長與火蜥蜴為主；弓箭手與火蜥蜴的遠程攻擊容易和近戰敵人形成夾擊。
* 建議攜帶弓弩逐一引敵，並準備修理光粉；不建議直接穿過整區敵群跑向 Boss。

### 第一大廳

* [ ] 從入口進入大型拱頂大廳，先清除靠近入口的亞倫騎士。
* [ ] 進入左側第一個門口，取得 **道具** 鏽斑硬幣×3。
* [ ] 逐批處理大廳內的亞倫騎士、亞倫騎士長與火蜥蜴。
    * 優先擊殺近戰敵人，再處理高處弓箭手。
    * 盡量沿左側前進，避免同時承受下層火蜥蜴的火球攻擊。
* [ ] 回收大廳中央的固定物品：
    * [ ] **道具** 光滑石頭×5。
    * [ ] **道具** 人像×3。
    * [ ] **道具** 不信仰者香料×1。
* [ ] 抵達大廳盡頭後，從地面的洞口向下跳。

### 格柵地板房至 Boss 霧門

* [ ] 進入格柵地板房，先處理近戰亞倫騎士，再處理使用亞倫大弓的騎士長。
* 格柵地板下方有火蜥蜴；站位時避免長時間停在其火球射線上。
* [ ] 取得 **道具** 輝滴石×5。
* [ ] 取得 **道具** 修理光粉×3。
* [ ] 前往格柵下方的房間，取得 **武器** 雙刃劍＋7。
* [ ] 回到主路並前往 Boss 霧門。
* 若只召喚 NPC 協助清理沿路敵人，可在霧門前使用黑水晶遣返；這樣不會讓 NPC 進入 Boss 戰，也不會增加 Boss 的生命與抗性。

### Boss：騎士亞倫 Sir Alonne

#### 可召喚 NPC

* [ ] 不屈的洛麗（Steel-willed Lorrie）。
* [ ] 流浪劍士艾多爾（Drifter Swordsman Aidel）。
* 兩個召喚記號都在進入記憶後的召喚石像附近。
* 兩位 NPC 都不涉及需要靠 Boss 存活勝利推進的支線；本戰召喚與否不影響 NPC 任務完成度。
* 召喚 NPC 會提高 Boss 的生命與抗性；若只需要他們協助跑圖，可在霧門前遣返。

#### 弱點與抗性

| 類型 | 近戰承傷效率 | 遠程承傷效率 |
|------|-------------:|-------------:|
| 打擊 |         100% |          80% |
| 斬擊 |         100% |          80% |
| 刺擊 |         100% |          80% |
| 魔法 |          70% |          33% |
| 雷   |          70% |          30% |
| 火   |          56% |          31% |
| 闇   |          70% |          40% |
| 毒   |          14% |          14% |
| 出血 |          50% |          50% |

* 打擊、斬擊與刺擊的近戰承傷效率相同，沒有特定物理弱點。
* **黑暗武器提醒：** 闇屬性近戰承傷效率為 70%，與魔法、雷相同；並非完全無效，但不能視為弱點。
* 火屬性近戰承傷效率只有 56%，不建議以火焰武器、焦炭松脂或火系咒術作為主力。
* 遠程魔法、雷、火與闇的承傷效率都明顯偏低；法術角色應保留足夠施法次數，並利用 Boss 完全收招後的空檔。
* 毒的有效率極低，不建議以毒作為主要打法。

#### 主要招式與應對

* 突進斬有快、慢兩種節奏；看到騎士亞倫壓低刀身後，不要固定時間提前翻滾，應確認實際衝刺時機。
* 兩次斜斬後可能接後跳突刺或延遲橫斬；第二刀後不要立刻貪刀。
* 遠距離時會蓄力發射闇屬性劍氣；向側邊翻滾後可縮短距離。
* 刀身發光後的突刺若命中，會造成抓技傷害並強化武器；看到刀身發光時向側面或右前方翻滾。
* 騎士亞倫將刀壓低時可能進入架勢並格擋反擊；不要在架勢期間主動揮擊。
* 生命低於約 60% 後會增加跳躍下劈與小範圍爆炸；避開落點後，只在確認沒有追加橫斬時反擊。
* 建議朝 Boss 的右側翻滾並貼近其背側；每次反擊以 1 下為基準，保留精力應付下一次突進。
* 盾牌可處理一般斬擊，但連段與突進會快速消耗精力；主要防禦仍以翻滾為主。

#### 特殊注意

* Boss 會讀取遠距離喝元素瓶的空檔並迅速突進；應在其完整收招、跳離較遠或被場地柱體遮住視線後治療。
* 若無傷擊敗騎士亞倫，他會在死亡前切腹；沒有額外道具或成就獎勵。
* Boss 生命低於約 30% 時會短暫踉蹌，可把握空檔安全輸出，但仍需保留精力。
* [ ] 擊敗騎士亞倫。
    * [ ] 取得 **Boss 魂** 騎士亞倫的靈魂。

### 騎士亞倫戰後收尾

* [ ] 擊敗騎士亞倫後，調查 Boss 房後方王座，取得最後 1 個 **關鍵道具** 鎔鐵之楔。
* [ ] 再次調查王座離開鐵之古王的記憶。
* [ ] 返回黑霧之塔，使用最後 1 個鎔鐵之楔破壞尚未處理的煤炭之像。
* [ ] 確認集齊 12 個碎片，並自動組成完整的「煤炭」娜德拉的靈魂。

## 後續追蹤

### 強化素材

### 鎔鐵惡魔的靈魂

* 擊敗藍色鎔鐵惡魔取得的仍是鎔鐵惡魔的靈魂。
* 擊敗藍色鎔鐵惡魔後，可使用鎔鐵惡魔的靈魂向武器匠歐尼菲克斯交換 **武器** 老舊的鎔鐵劍。
* 老舊的鎔鐵劍使用龍骨化石強化，最高可強化至＋5，共需 15 個。
* 鎔鐵劍與老舊的鎔鐵劍各消耗 1 份鎔鐵惡魔的靈魂；兩把都要收集時，需要保留 2 份。

### 騎士亞倫的靈魂

* 可向武器匠歐尼菲克斯以騎士亞倫的靈魂加 18,000 靈魂交換 **武器** 亞倫妖刀。
* 亞倫妖刀使用龍骨化石強化，最高可強化至＋5，共需 15 個。
* 本周目只有 1 個交換品，因此騎士亞倫的靈魂全收集只需 1 份。
* 擊敗騎士亞倫後，馬格赫拉德會販售亞倫套裝；亞倫套裝使用光輝楔形石強化。

### 「煤炭」娜德拉的靈魂

* 黑霧之塔共有 11 座煤炭之像；使用 11 個鎔鐵之楔可取得 11 個靈魂碎片。
* 煙之騎士另掉落 1 個碎片，合計 12 個。
* 完整的「煤炭」娜德拉的靈魂可交換：
    * 武器匠歐尼菲克斯：聖鈴「吶喊之鈴」，另需 20,000 靈魂。
    * 奧斯特羅的史垂德：咒術「咆哮」，另需 45,000 靈魂。
* 兩項交換各消耗 1 份完整靈魂，因此全收集需要跨周目。
