## 區域攻略

* 如蜜 → 不死靈廟 → 死者棄置處 → 汎克拉德
* 本段目標：擊敗汎克拉德，解鎖阿馬那祭壇的王之靈魂與國王套裝，並進入王之記憶完成後續對話。
* 米勒的魯卡提耶與烏格的班荷特任務均已完成，本段不再追蹤任務計次。
* 汎克拉德只能單人挑戰，**沒有 NPC 可召喚支援**。

### 前置確認：巨人們的靈魂

* [x] 黑溪谷巨人洞穴：巨人們的靈魂×1。
* [x] 龍祭壇古龍：巨人們的靈魂×1。
* [x] 巨人汪姆德的回憶：巨人們的靈魂×1。
* [x] 巨人洛的回憶：巨人們的靈魂×1。
* [x] 巨人奧捷的回憶：巨人們的靈魂×1。
* [x] 確認目前持有巨人們的靈魂×5。
* **全部保留，不使用、不捏掉。**
* 汎克拉德原本具有極高減傷：沒有巨人們的靈魂時約為正常防禦的32倍；每持有1個會再除以2。持有5個時降至正常倍率。

|--------------:|-----------------:|
| 0             |              ×32 |
| 1             |              ×16 |
| 2             |               ×8 |
| 3             |               ×4 |
| 4             |               ×2 |
| 5             |               ×1 |

### 返回不死靈廟

* [ ] 從如蜜傳送至「不死靈廟－死者棄置處」。
* [ ] 前往先前取得國王戒指的區域，找到在房間內徘徊的汎克拉德。
* 汎克拉德一開始不會立刻進入Boss戰，需要主動攻擊數次才會正式敵對。
* 不要消耗任何巨人們的靈魂；只要放在物品欄中即可生效。

### Boss：汎克拉德 Vendrick

* **NPC召喚：無。** 汎克拉德只能單人挑戰。
* 你目前持有5個巨人們的靈魂，已經是最低防禦狀態，不需要再補任何前置。
* 汎克拉德對闇抗性較高；魔法、火、雷屬性抗性約為中等。若使用附魔，**不要特別以闇屬性作為優先選擇**。
* 物理打法重點不在特定「刺／砍／打」弱點，而是安全貼身輸出；使用熟悉、攻速穩定的武器即可。
* 汎克拉德攻擊傷害非常高，盾牌通常會承受大量精力傷害；以翻滾與走位優先。
* 最穩定站位：貼近汎克拉德的**左後方／左腿附近**，持續繞到背後。
* 常見攻擊：
  * 大劍橫掃：延遲明顯，不要太早翻滾。
  * 大劍縱劈：向側面閃避後可反擊。
  * 跳躍／後撤：重新貼近左後方，不要貪刀。
* 若汎克拉德被逼到牆邊，先拉回房間中央，避免無法繞到背後。
* [ ] 擊敗汎克拉德。
  * 汎克拉德Boss本身**不會直接掉落王之靈魂**。
  * 擊敗後解鎖阿馬那祭壇的王之靈魂與國王套裝。

### 擊敗汎克拉德後：阿馬那祭壇回收

* 路線：阿馬那祭壇「崩塌遺跡（Crumbled Ruins）」附近 → 左側支路 → 龍騎兵守衛的門。
* 此門除了擊敗汎克拉德外，進入時需要保持**活人狀態**。
* [ ] 使用人像恢復活人狀態。
* [ ] 開啟龍騎兵守衛後方的門。
* [ ] 取得 **王之靈魂（Soul of the King）**。
* [ ] 取得 **國王套裝（King's Set）**：
  * [ ] 國王王冠（King's Crown）。
  * [ ] 國王鎧甲（King's Armor）。
  * [ ] 國王護手（King's Gauntlets）。
  * [ ] 國王腿甲（King's Leggings）。
* **王之靈魂保留，不使用。** 全收集需要跨周目取得3份，分別交換統治者之劍、王之盾、王之特大劍。

### 王之記憶

* 擊敗汎克拉德後，持有灰霧核心即可調查不死靈廟中汎克拉德留下的裝備，進入 **王之記憶（Memory of the King）**。
* [ ] 進入王之記憶。
* [ ] 與人形汎克拉德對話至內容循環。
* 現階段尚未持有三個DLC王冠，因此無法完成王冠相關的最終祝福事件；後續取得三個DLC王冠後需要再回來。

## 後續追蹤

### 王之靈魂交換

王之靈魂每周目只能取得1份，全收集需要3份：

| 王之靈魂 | NPC | 交換物 | 本周目安排 |
|----------|-----|--------|------------|
| 第1份 | 武器匠歐尼菲克斯 | 統治者之劍（Ruler's Sword） | 待交換 |
| 第2份 | 武器匠歐尼菲克斯 | 王之盾（King's Shield） | NG+ |
| 第3份 | 武器匠歐尼菲克斯 | 王之特大劍（King's Ultra Greatsword） | NG++ |

* [ ] 本周目第1份王之靈魂保留，後續向歐尼菲克斯交換其中一件。
* 不使用營火探究者重打汎克拉德來期待第二份王之靈魂；王之靈魂每周目只會出現一次。

### DLC 王冠與汎克拉德祝福

* [ ] 深淵王的王冠（Crown of the Sunken King）。
* [ ] 鐵之古王的王冠（Crown of the Old Iron King）。
* [ ] 白王的王冠（Crown of the Ivory King）。
* [ ] 三個DLC王冠全部取得後，帶著國王王冠與三個DLC王冠再次進入王之記憶與汎克拉德對話。
* 完成後取得汎克拉德的祝福：佩戴四頂王冠中的任一頂時，死亡不再增加遊魂化，並免疫詛咒；效果只限目前周目，不繼承到下一周目。

### 強化素材追蹤

* 本段主路線沒有新的固定餘燼、光輝楔形石或龍骨化石需要特別回收。
* 國王套裝使用光輝楔形石強化；本段先以收集為主，不要求立即強化。
