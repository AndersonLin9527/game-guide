# DarkSoul 2-Walkthrough-攻略-王都多蘭古雷格 02_鏡之騎士

依附件最新進度，下一段安排： **王城中層 → 王城後半收集 → 鏡之騎士 → 阿瑪那祭壇第一座營火。**

本次重點是 **元素瓶升到12瓶＋5，以及讓班荷特取得第1次有效存活勝利**。你已完成的王城前半、班荷特對話與王城遠古暗穴，不必重跑。

以下可直接勾選。這次部分攻略頁無法完整讀取，因此不把未核實的寶箱內容列成「完整全收集」，也不硬填未確認的繁中名稱。

**1．出發準備**

* [ ] 從「王城中層」營火出發。
* [ ] 準備慣用近戰武器、弓箭、滴石，以及魔法「修理」。
* [ ] 攜帶人像；探索時不必急著使用，清完 Boss 前通道再恢復活人。
* [ ] 確認目前不是強者誓約，避免無法召喚班荷特。
* [ ] 保留營火探究者，本段不使用。

**2．啟動中央升降梯**

從營火繼續前進，會到達中央升降梯所在的房間。 **升降梯尚未啟動時，先找旁邊的長梯往上爬。**

* [ ] 爬長梯，抵達有巨人吸魂機關的房間。
* [ ] 將附近可活動的敵人引到巨人機關旁，再擊殺。
* [ ] 確認機關吸收靈魂並啟動，讓中央升降梯可以使用。
* [ ] 若殺敵後沒有反應，將下一隻引得更靠近機關；不用消耗背包中的靈魂道具。

這裡要的是 **敵人死在機關附近**，不是與機關互動，也不需要法洛斯之石。

**3．先走後半探索路線，開捷徑、找元素碎片**

啟動機關後，繼續探索上層通道與後續房間，最後開啟回到王城中層附近的捷徑。

* [ ] 清理沿途敵人，遇到多人房間先用弓逐隻引出。
* [ ] 遇到馬型敵人的大廳時，先清周圍敵人，再處理馬。
* [ ] 拾取該敵人的掉落物，留意「高達守護戒指」（Gower’s Ring of Protection）。
* [ ] 檢查大廳及後續房間的寶箱；開箱前先辨識寶箱怪。
* [ ] 留意牆面面具機關，不在射擊範圍內久站。
* [ ] 探索通往下層、返回營火的支路，取得 **王都元素碎片**。
* [ ] 開啟返回王城中層的捷徑。
* [ ] 回如蜜交付碎片，確認元素瓶成為 **12瓶＋5**。

**元素碎片應在前往鏡之騎士前補到；若已抵達 Boss 霧門仍沒拿到，先回頭檢查這段支路。**
王城中層之後可取得碎片的位置說明，可對照 [王都區域資料](https://darksouls2.wikidot.com/drangleic-castle)。

這段另要留意咒術 **「火焰風暴」（Firestorm）**
，以及寶箱內的龍骨化石與晾衣長刀；法術與武器即使已有，也可以保留本次取得紀錄。[王城流程影片的收集段落](https://www.youtube.com/watch?v=WmRVfwq_JLw&t=3016s)

**4．搭升降梯上塔，取得鑰匙**

回到中央升降梯，搭乘至塔頂。你會看到被拘束的人形，以及後方關著人的房間。

* [ ] 搜查塔頂房間的寶箱。
* [ ] 取得 **王之迴廊鑰匙 Key to King’s Passage**，即開啟下方通往鏡之騎士道路的鑰匙。
* [ ] 取得魔法 **「強力法術盾」Strong Magic Shield**。
* [ ] 拾取其他寶箱物品，包含火種、靈魂容器。
* [ ] 記住被拘束人形的位置，留待後續返回處理。
* [ ] 搭升降梯下樓，使用新鑰匙開啟通道。

**塔頂被封住的房間目前不能完成事件，先記錄位置即可。**
不需要攻擊裡面的人。鑰匙與強力法術盾的路線可對照 [塔頂收集影片](https://www.youtube.com/watch?v=WmRVfwq_JLw&t=3352s)。

**5．清理通道，再召喚班荷特**

開門後是通往鏡之騎士的長廊，兩側部分石像會活動。

* [ ] 緩慢推進，讓會活動的石像逐隻接近。
* [ ] 收取長廊兩側的發光物。
* [ ] 清完霧門前的敵人。
* [ ] 使用人像恢復活人狀態。
* [ ] 在霧門附近找到 **烏格的班荷特**召喚符，確認名字後召喚。
* [ ] 確認班荷特跟上，再進入霧門。

你已完成王城中層對話； **本次需要的是「召喚他，並讓他活到 Boss 死亡」**。

**6．鏡之騎士打法與任務判定**

你的持久力目前10，使用大型武器時，建議每次空檔先以 **一刀後保留翻滾體力**為原則。

* 等他連段或跳斬結束，再靠近攻擊。
* 優先打側面、背面，避開大鏡盾；正面攻擊容易被擋。
* 他轉向班荷特時，你靠近輸出，減少班荷特持續承受攻擊。
* 他把鏡盾立在地上召喚援兵時，注意新敵人出現，避免被兩面夾攻。
* 補血前先拉開距離，別在近身連段途中喝元素瓶。

任務勾選：

* [ ] 班荷特已進入 Boss 場地。
* [ ] 擊敗鏡之騎士。
* [ ] Boss 死亡時班荷特仍存活。
* [ ] 符合以上條件後，班荷特由 **0／3 → 1／3**。
* [ ] 保留鏡之騎士的靈魂。

**如果班荷特先死亡，而你仍未擊敗 Boss，想保住本次計次機會就用返回骨片撤退，再重新召喚挑戰。** 如果已經擊敗
Boss，就如實記錄沒有增加次數，不使用探究者補打。

**7．戰後收集與本段終點**

* [ ] 離開 Boss 戰場前，檢查後方、升降梯周圍的寶箱。
* [ ] 留意魔法 **Soul Bolt**；繁中名稱等你拾取畫面確認，不先自行翻譯。
* [ ] 搭乘後方升降梯往下。
* [ ] 抵達阿瑪那祭壇，點燃第一座營火。
* [ ] 本段在此結束，祭壇水域留作下一段攻略。

完成後回報這幾項即可：

| 項目      | 成功完成後                                               |
|-----------|----------------------------------------------------------|
| 本篇 Boss | 22／32                                                   |
| 全部 Boss | 22／41（53.7%）                                          |
| 班荷特    | 存活勝利1／3；需實際確認                                 |
| 元素瓶    | 12瓶＋5；需交付碎片                                      |
| 收藏      | 高達守護戒指、火焰風暴、強力法術盾、Soul Bolt 的取得情況 |
| 下一段    | 阿瑪那祭壇 → 歌唱惡魔                                    |

## 8. 收集檢查

範圍：王城中層 → 王城後半 → 王之迴廊 → 鏡之騎士 → 阿瑪那祭壇第一座營火。

### 王城後半：機關、支路與寶箱

* [ ] 啟動 **機關**：將敵人引至巨人石像附近擊殺，啟動中央升降梯。
* [ ] 取得 **魔法**：靈魂大劍（Soul Greatsword）；位於長梯上方、巨人機關附近房間的寶箱。
* [ ] 取得 **聖鈴**：夸特之鈴（Caitha's Chime）；位於長梯上方、巨人機關附近房間的寶箱。
* [ ] 取得 **武器**：古老騎士大鎚（Old Knight Hammer）；王城後半寶箱。
* [ ] 取得 **戒指**：高達守護戒指（Gower's Ring of Protection）；擊敗樓梯大廳的馬型敵人後拾取。
* [ ] 取得 **咒術**：火焰風暴（Firestorm）；樓梯上方、古老騎士守護的寶箱。
* [ ] 取得 **武器**：晾衣長刀（Washing Pole）；處理同段寶箱怪後拾取。
* [ ] 取得 **強化素材**：龍骨化石；同段寶箱怪掉落。
* [ ] 取得 **道具**：元素碎片；探索後半通往營火捷徑的支路寶箱。
* [ ] 開啟返回「王城中層」的捷徑。
* [ ] 回如蜜交付元素碎片，確認元素瓶升至12瓶+5。

### 中央升降梯塔頂

* [ ] 取得**鑰匙**：王之迴廊鑰匙（Key to King's Passage）。
* [ ] 取得**魔法**：強力法術盾（Strong Magic Shield）。
* [ ] 取得**道具**：靈魂容器。
* [ ] 取得**強化素材**：火種。
* [ ] 記錄塔頂被拘束人形與封閉房間的位置；後續取得對應鑰匙後再回來。
* [ ] 搭乘升降梯下樓，使用王之迴廊鑰匙開門。

### 王之迴廊與鏡之騎士

* [ ] 收取王之迴廊兩側屍體上的道具。
* [ ] 清除霧門前會活動的石像敵人。
* [ ] 恢復活人狀態，召喚 **NPC**【烏格的班荷特】。
* [ ] 擊敗 **Boss**【鏡之騎士】。
* [ ] 確認班荷特在Boss死亡時仍然存活；成功後將有效存活勝利更新為1／3。
* [ ] 取得並保留**Boss魂**：鏡之騎士的靈魂。

### 鏡之騎士後方寶箱

* [ ] 取得**魔法**：靈魂閃光（Soul Bolt）。
* [ ] 取得**戒指**：法術晶石戒指＋2（Spell Quartz Ring +2）。
* [ ] 取得**道具**：營火探究者×3；僅收集，暫時不使用。
* [ ] 搭乘後方升降梯，抵達阿瑪那祭壇。
* [ ] 點燃**火點**：阿瑪那祭壇第一座營火。

### 留待後續，不列入本段完成條件

* [ ] 塔頂封閉房間：取得對應鑰匙後返回，收集死者戒指。
* [ ] 鏡之騎士相關武器、盾牌與防具：另行安排Boss魂交換及商店購買。
* [ ] 石像騎士等敵人的稀有裝備掉落：留待後期集中刷取。
